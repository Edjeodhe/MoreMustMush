## 2. 검수 방법

1. `db.json` String 시트를 언어별 TSV로 내보내고 자동 검사: 자리 표시 `{n}`, 리치 텍스트 태그, 줄바꿈 개수, 한글 잔존, 길이 비율, 빈 칸, 같은 원문의 중복.
2. 언어별 검수 에이전트가 원문과 번역을 전수 대조: 오역, 용어 일관성(약 40개 용어 표), 문법, 어조, 버섯 종 이름, UI 길이.
3. RU·UK는 `Loc.F`의 `{0}`에 실제로 들어가는 값을 코드에서 확인해서 성·격·복수형 문제를 찾았다.
4. 코드 검수 에이전트가 `Loc.T/Loc.F` 호출처, 보간 문자열, 하드코딩 영어, 폰트 글리프, 씬 `LocText` 키를 점검했다.

보고서는 `loc/` 폴더에 있다.

- 오역·종 이름: 의뢰 Favors→Quests(901157, 900203, 900641), 싸리버섯·산호버섯 이름 충돌 해소(Yellow Coral / Sea Coral), 선녀낙엽버섯 Fairy Ring Mushroom, 간버섯 Cinnabar Polypore, 잔나비걸상버섯 Artist's Conk.

### 3-4. Русский

### 3-5. Українська

## 9. 하지 않은 것

- **선택 사항**: EN 무당버섯·상황버섯·능이·화경, RU 상황·능이, UK 목이버섯·목장→농장, JA 霊芝→マンネンタケ·구역→ゾーン·能力値, JA `!` 뒤 공백, UI 길이 확인 줄.
- **복수형 엔진**: `Loc`에 복수형 처리가 없어서 RU·UK는 "명사: {0}" 꼴로만 피했다. 숫자에 따른 어미 변화는 지원하지 않는다.
- **기본 언어**: `Loc.DefaultLang = "en"` (기기 언어 무시)는 그대로.
- **쓰지 않는 번역 줄**: `after:… cnt:` 데이터 태그 45줄, `이`/`가`, 코드 주석(901323), 옛 UI 문구 약 436줄이 번역표에 남아 있다. 화면에는 안 나오지만 번역 비용과 폰트 글자 수를 늘린다. 정리 여부는 사용자 판단.

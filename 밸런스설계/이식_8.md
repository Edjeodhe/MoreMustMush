# 이식_8 — 모바일 노드 개편용 목표 곡선 (노드 무관) · theory · 2026-10-23

8회차 결과를 노드 이름 없이 "내부 판 n에서 이 값"으로 정리한다. 새 노드 배치는 아래 목표를 맞추도록 가격·효과를 정하고, 봇 시뮬(BalanceSim)과 D1 지표로 확인한다. 근거·계산은 `이론_8.md`(특히 8-R2), 원자료 `BalanceData/r8/theory/`. 수치는 모델값 + T8-1 측정이며 사람 쪽은 지표 B(표본 27~38명, 참고용)로 맞췄다.

## 1. 판 수입·구매 (사람 기준, 내부 판 = 튜토리얼 T1~T4 포함, 표시 = 내부 − 4)
| 내부 판 | 판당 판 수입 배율 | 판당 구매 수 | 다음 구매 가격 / 판 수입 | 눈에 보이는 성장 |
|---|---|---|---|---|
| 1 | (첫 판 17~20) | 첫 판 뒤 **2개** 살 수 있게 (첫 두 구매 합 ≤ 첫 판 수입 × 0.75) | ≤ 0.8 | 첫 구매 중 하나는 수입 ×1.5 이상(예: 타격 점수 2배) |
| 2~8 | **≥ ×1.5** (구간 평균; 판별로도 ×1.2 아래 판 없게) | 2~3 | ≤ 0.6 | 군락 2 → 4, 판 시간 +2~5초 |
| 9~13 | ≥ ×1.35 | 2~3 | ≤ 0.6 | **영구 수확기 2개 ≤ 판 10**, 군락 6 |
| 14 보스 | — | — | — | |
| 15~23 | ≥ ×1.25 | 2 이상 | ≤ 0.8 | **수확기 3개 ≤ 판 16**, 꼬마 수확기 ≤ 판 14, 군락 12 |
| 24 보스 / 25 지역(밤) | 지역 해금 ×10 뜀은 유지 | — | — | |
| 25~33 | ≥ ×1.25 | 2 이상 | ≤ 0.8 | 군락 18 (판 30) |
| 35~48 | ≥ ×1.15 | **1 이상 (0구매 판 ≤ 20%)** | ≤ 1.5 | 수확기 4개 ≈ 판 32 |
| 49 지역(들판) · 50~64 | ×10 뜀 뒤 ≥ ×1.12 | 1 이상 | ≤ 1.5 | |
- 근거: 판당 배율 r = (구매 하나의 수입 배율 m)^(판당 구매 수 n). 유지하려면 가격 사다리 비 g ≈ m. m ≈ 1.2면 ×1.5에 n ≈ 2.2.
- 싼 구간(가격이 판 수입의 0.6 이하인 노드)의 **2/3 이상은 m ≥ ×1.1**. 수입 0인 노드(바 스킬·초반 공격력·버섯 수확량)는 아주 싸게 두거나(다른 것과 같이 사짐) 뒤로 민다 — 한 판의 유일한 구매가 되면 그 판 성장이 0.
- 측정 탄력(판 수입 ∝ x^b): 타격 점수(등급 기본 + 고정값) 1 · 정산 배율 1 · 판 시간 0.8 · 군락 수 0.7 · **영구 수확기 1.04(0→1개 ×2.06, T8-1)** · 필드 넓히기는 군락 +와 밀도 −가 상쇄(≈ ×0.9~1.0).

## 2. 보스
**체력 식: Hp = D⁻¹ × 사람 유효 DPS × (판 시간 − 2)**, D = 사람 중앙값이 판 안에 주는 피해 ÷ 체력.
| 내부(표시) | 목표 사람 실패율 | 목표 D(중앙) | 평균 도전 | 비고 |
|---|---|---|---|---|
| 14(10) | ≤ 15% | ≈ 3 (판 시간 1/3에 처치) | 1.0~1.2 | 첫 보스. 유도 같은 보스 특화 스킬 없이 잡혀야 함 |
| 24(20) | ≤ 15% | ≈ 2.8 | 1.0~1.2 | 지금 값은 실패 ≈ 0%(허들 없음 수준) — 이식 때 10~15%로 |
| 34(30) | ~40% | ≈ 1.3 | 1.6~1.7 | |
| 44(40) | ≤ 50% | ≈ 1.0 | 1.7~2.0 | 지표 B 84%·4.75판은 벽 |
| 54(50) | 50~60% | ≈ 0.8~0.9 | 2.0~2.5 | 44보다 쉽지 않게 |
- **사람 유효 DPS(유도 없음)**: 지표 B 역산 ≈ 1.0 × 공격력 × 영구 수확기^0.7 (14: 2.9/초 @ 공격력 2.75·수확기 1, 24: 7.5/초 @ 4.95·2).
- **사람/봇 보정**: 봇(SKILL 0.6·1.0)은 보스를 직접 겨눠 사람보다 DPS가 5~40배다 → 보스 도전 수·처치율로 체력을 맞추지 않는다. 봇은 **DPS 비**(스킬 있음/없음, 상태 A/B)만 잰다. 사람 실패율 분포는 D1의 보스 실패율 q와 실패 판 남은 HP L로 로그정규 ln D ~ N(mu, s)를 맞춘다(E[D | D<1] = 1 − L, `boss_fit.py`).
- **유도(바→보스 직행) 실측 배율 M = ×1.85~1.91**(34·44·54, 레벨 2~4 같음, T8-1). 보스 직행류 스킬을 넣거나 뺄 때 사람 DPS를 이만큼 곱하거나 나눈다.
- 한 바퀴 뒤(표시 60~) 체력 배율 = 마지막 보스 × 1.1.

## 3. 무한 성장 노드 (덧셈 규칙)
- 효과 = **1 + step × L** (곱 금지). step = DB `Efx_Lv1` − 1 (지금 공격력 0.07 · 골드 0.04).
- 가격은 곱(시작가 × 1.076^L) → 공격력이 쓴 골드의 로그로만 는다. 레벨 100: 공격력 ×8 · 골드 ×5 (곱이던 때 ×868 · ×50.5). 지역 ×10마다 적이 따라잡아 뒤 스테이지 적이 의미를 갖는다.
- 골드 무한 노드가 곱이면 골드 → 레벨 → 골드 되먹임 폭주가 생긴다(덧셈이면 없음).

## 4. 가격 사다리 규칙
- 노드 안 다음 레벨 ≤ **×4**.
- 화면 가격 전체를 정렬했을 때 바로 앞 대비 ≤ ×2(목표 ×1.4), **BalanceSim STEP_FIX 1.8을 넘지 않게**(넘으면 BalanceJob/EnforceShape가 앞 가격을 올린다).
- 다음 단계 첫 레벨의 효과 +1당 골드 ≤ 앞 단계 마지막 레벨의 0.7배(효율 넘김).
- 지역 경계 사이(내부 25~48)에 "판 수입의 2~10배" 가격 구간이 생기면 정체 → 그 구간 칸을 판 수입 × 0.75~1.5로.

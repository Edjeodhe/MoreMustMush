# 9회차 요청 — 후반(표시 50~100) 밸런스 (2026-10-23)

사용자 원문: "후반(표시 50~100) 밸런스 회차를 에이전트 팀으로 시작해줘. 목표 곡선, 사람 기준 반복 보스 체력, 바다 진입, 트리 완료 뒤 살 거리까지"

**8회차 방침은 그대로 지킨다**: `밸런스설계/8회차_요청.md`, `이식_8.md`.
- 지표 근거
- 인크리멘탈은 즉각 성장 피드백
- 수치는 노드 무관 목표 곡선으로 남긴다(모바일 노드 개편에 이식)
- 무한 노드는 덧셈
- 바 자석(유도) 없음
- DB 칼럼·새 Const는 꼭 필요할 때만, 늘리면 보고
- 엑셀은 COM으로만 쓴다
- 커밋은 사용자 확인 뒤에 한다

## 요청
| # | 내용 |
|---|---|
| L1 | **후반 목표 곡선**: 표시 50~100에서 판 수입 배율·판당 구매 수·다음 가격/판 수입·시간(표시 60·80·100 도달 분). 8회차 이식 기준의 연장 |
| L2 | **사람 기준 반복 보스 체력**: 표시 60~100(보스 한 바퀴 뒤 `BOSS_LOOP_HP_MUL`, 같은 보스 종류 반복)을 사람 기준 허들로. 지금은 봇이 전부 첫 도전에 잡는다 |
| L3 | **바다 진입**(표시 75): 들어가서 잡을 수 있게. 지금 봇은 공격력 250~560 < 바다 버섯 체력의 절반이라 안 들어간다 |
| L4 | **트리 완료 뒤 살 거리**: 골드 트리가 표시 69~71에 끝나고, 그 뒤 성장은 무한 노드 판당 약 1레벨(판 수입 판당 ×1.05~1.08)뿐이다 |

## 사용자 결정 (이론_9 권장안 질문에 대한 답)
| 항목 | 결정 |
|---|---|
| 바다 지역 배율 ×10 → ×2.5 (권장안) | **채택 안 함.** 사용자: "후반부는 시간적 허들이 필요함". 끝이 안 보이는 벽은 안 되지만, 쉽게 넘는 것도 아님 |
| 시간 허들 | **허들마다 10~20분**(바다 진입, 보스 60~100 각각): 파밍하며 강해져 넘는 데 걸리는 시간. 사람 기준 표시 100 약 3시간 |
| 세계수 시스템 | 사용자: "세계수 시스템 때문에 시간 허들을 뛰어넘는 건 있음" → 세계수(방치 보상·꼬마·성장 보너스 등)가 시간 허들을 줄여 준다는 점을 모델에 넣는다. 봇은 세계수를 안 쓰니 그 몫을 따로 추정 |
| 무한 노드 | 끝없는 투지 **+15%p**(8회차 +7%p에서 변경), 가격비 **×1.06**(1.076에서). 풍년 +4%p 그대로, 덧셈 유지 |
| 반복 보스 60~100 | **점점 어렵게** (예: 60 약 50% → 100 약 70%). 보스별/바퀴별 배율이 필요할 수 있음 — 새 Const보다 코드 식 우선, 늘리면 보고 |

## 사용자 결정 2 (9-R c안 질문에 대한 답)
| 항목 | 결정 |
|---|---|
| 반복 보스 체력 | c안·b안 대신 **"반복 구조고 모바일 방치형처럼 진행할 거니 계속해서 허들 및 증가"** → 보스 체력은 바퀴마다 끝없이 오르는 반복 허들(상한 없음), 성장도 끝없이 따라가는 구조 |
| 실패마다 체력 −15% | **넣지 않음.** 대신 **"무한 노드 성장 요소를 좀 더 추가 — 예) 수확기 +1, 스킬 확률 증가, 스킬 데미지 증가, 속도 증가 등"** |
| 세계수 | 위 답에서는 "이번엔 그대로"였으나 바로 뒤 추가 지시: **"세계수 스테이지에 따라 골드 보상 어느 정도 보정도 줘"** → 세계수 단계(성장 스테이지)에 비례하는 골드 보상 보정을 넣는다 |

## 사용자 결정 3 (9-R2 질문에 대한 답)
| 항목 | 결정 |
|---|---|
| 사람 보스 모델 | **어려운 쪽(c)** 에 맞춘다. 새 빌드 지표로 다시 맞춘다 |
| 판당 실패율 vs 시간 허들 | **"시간 허들 우선. 시간 허들도 스테이지가 진행됨에 따라 점점 늘어나야 함 — 모바일 게임 참고"** |
| 새 무한 노드 상한 | **상한 더 넓게** (발동률 ×2·속도 +30%·수확기 +4보다 넓게, 모바일 성능 고려) |
| 표시 120 이후 성장 축 | **모바일 개편 때** (이번엔 표시 100까지) |

## 사용자 결정 4 (9-R3 질문에 대한 답)
| 항목 | 결정 |
|---|---|
| 판당 실패율 67~84% | **"모바일 게임처럼 시간을 통해 강화를 해서 허들을 뚫는 것"** → 실패율 자체는 괜찮다. 핵심은 지면 파밍(시간)으로 강해져 넘는 구조가 실제로 돌아가는 것. 파밍 판마다 체감되는 성장이 있어야 한다 |
| 새 싱크 상한 | **기기 프레임 측정 뒤 더 넓힌다** (T9-1에 공 수·속도별 프레임 측정 포함) |
| 세계수 골드 보정 크기 | **"밸런스 보고 잡아줘. 후반에는 세계수가 주로 바뀔 것"** → 값은 팀이 허들·도달 시간을 보고 정한다. 후반 성장의 주 변화 축이 세계수가 된다는 전제로 설계(봇은 세계수를 안 쓰니 세계수 몫을 따로 모델링) |
| 표시 100 이후 (약 280~300 벽) | **가안으로 잡는다** (mul 600 고정은 가안, 모바일 개편 때 다시) |

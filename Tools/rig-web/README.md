# rig-web — 정령 리그2 작업장

버섯 정령(진화 꼬마) 리깅을 처음부터 다시 만든 **리그2**를 브라우저에서 재생·조정·저장하는 도구.
목표는 사실적인 움직임이다: 무게(스프링), 관성·따라오는 동작(관절점 가속도로 흔들리는 진자), 디딘 발이 땅에 붙는 걷기(역진자 골반), 예비 동작, 착지 찌그러짐.
Unity C#으로 1:1 옮길 수 있게 이름과 계층을 C# 모양으로 맞췄다. Unity 쪽 코드는 아직 바꾸지 않았다.

## 실행

```bash
node Tools/rig-web/serve.mjs 5178        # → http://127.0.0.1:5178/
```
Claude 미리보기에서는 `preview_start {name: "rig-web"}`(`.claude/launch.json`)로 띄운다. Node 내장 모듈만 쓴다.

## 파일

| 파일 | 내용 |
|---|---|
| `make_parts.py` | 기존 진화 그림(`Characters/Evo`)을 관절 단위로 잘라 `Assets/Resources/Characters/Rig2/r2_*`에 저장한다. ★2·★3은 가슴/치마, 아래팔/손, 다리/신발로, ★0·★1은 갓/대/발로 나눈다. 표정 blink·happy·surprise·effort도 여기서 만든다. 기존 그림은 덮어쓰지 않는다. `--json`을 붙이면 `spirit_rig2.json`을 새로 쓰고, `--preview`를 붙이면 `Logs/Screens/rig2_parts_<id>.png`를 만든다. |
| `gen_parts.mjs` | 코덱스로 부위별 파츠를 한 장씩 생성한다(불 정령 ★3 시범, `--ref`로 확정 그림을 넣어 그림풍 유지). 원본은 `Art/Raw_Dream/rig2/gen_*.png`(게임 밖)에 두고, 프롬프트는 `parts_prompts.md`에 남긴다. 이미 있는 원본은 건너뛴다(`--force`로 다시 생성). |
| `fit_gen_parts.py` | 원본을 정면 그림 크기에 맞춰 `Characters/Rig2/gen_fire_3_<front|side|back>_*`로 저장한다. 다리는 허벅지/정강이/신발로 나눈다. spirit_rig2.json의 fire_3에 정면 다리(무릎)와 `side`·`back` 칸을 넣는다(다시 돌리면 웹에서 고친 값이 지워짐). |
| `bundle.mjs` | 서버 없이 열리는 한 장짜리 `dist/spirit_rig2.html`을 만든다. |
| `rig2.js` | 리그2 본체(`SpiritRig2`): 계층 만들기, 모습 세우기, 동작 함수, 스프링·진자, 다리 IK, 표정. → C# `SpiritRig2.cs` |
| `mush_rig.js` | ★0·★1 전용 버섯 리그(`MushRig`). 사람형 리그2와 따로 돈다. → C# `MushRig.cs` |
| `unity.js` | Unity 흉내: Mathf, Transform(T·R·S), SpriteRenderer, 결정적 난수 |
| `rigjson.js` | JSON 읽기·쓰기. 파이썬 `json.dump(indent=1)`과 같은 형식으로 쓰고, 숫자는 읽은 글자 그대로 유지한다. 고치지 않고 저장하면 diff 0. |
| `serve.mjs` | 정적 서버 + `/api/sprites`(SpriteDB와 같은 키·우선순위, .meta의 피벗·PPU) + `/api/save`(Temp에 백업한 뒤 저장) + `/api/shot`(`Logs/Screens/*.png`) |
| `index.html`, `app.js`, `style.css` | 화면 |

데이터: `Assets/Resources/Rig/spirit_rig2.json` = `{ looks: [...], motion: {...} }`
- 좌표는 리그 단위(그림 px/100)이고, 원점은 발바닥 가운데, y는 위가 +다.
- 부품 `{sprite, x, y}`의 x,y는 서 있을 때 그림 중심이다. sprite는 `Characters/` 아래 키(예 `Rig2/r2_fire_3_chest`)다.
- 팔·다리는 보는 쪽 왼쪽 값만 적는다. 오른쪽은 어깨·엉덩이를 축으로 뒤집어 쓴다.
- 관절: `waist neck hairRoot capTop shoulderL/R elbow wrist hipL/R ankle sole`. ★0·★1은 `capJoint capTop ankle ankleR`.
- 작업복: `<sprite>_<outfit>` 그림이 있으면 그것을 쓴다(가슴·치마·목 프릴).
- `motion`은 동작 상수다. 없으면 `rig2.js MOTION_DEFAULTS`를 쓴다. 상수를 하나라도 바꾸면 전부 들어간다.

## 화면

- **왼쪽**
  - 정령·모습(★)·복장·표정(자동 또는 고정)·좌우 반전을 고른다.
  - 동작 단추: 대기, 걷기, 나르기, 일하기, 오르기, 폴짝(계단), 춤, 하트, 잠, 들림, 떨어짐, 점프, 놀람, 돌기, 착지, 손 흔들기, 기지개, 두리번, 폴짝(한 번), 하품, 수동 포즈.
  - 재생: 일시정지, 한 프레임, 속도, 시간 스크럽. 고정 1/60초 단계로 처음부터 다시 계산하므로 스크럽해도 결과가 같다.
  - 보기: 뼈·관절, 부품 손잡이, 체크 배경, 땅 눈금·사다리(발이 붙는지 확인), 실제로 이동하며 보기, 모든 정령 한꺼번에 보기, 확대.
- **가운데 캔버스**
  - 관절점을 드래그하면 그 축만 옮긴다(그림은 그대로).
  - **Shift**+드래그는 축과 그 아래 그림을 같이 옮긴다. 예: 어깨를 Shift로 끌면 팔 전체가 따라온다.
  - 부품 손잡이(네모)는 그림 위치를 옮긴다. "좌우 관절 같이"를 켜면 어깨·엉덩이가 대칭으로 움직인다.
  - 빈 곳을 드래그하면 화면이 이동한다. 들림 동작에서는 정령을 들고 흔드는 동작이 되어 진자처럼 흔들린다.
  - 휠로 확대·축소한다.
- **오른쪽 탭**
  - 부위·관절: 숫자 칸과 그림 이름을 고친다. 바뀐 줄은 색이 달라진다.
  - 동작 상수: 슬라이더와 숫자 칸. 바꾸면 재생에 바로 반영된다.
  - 수동 포즈: 자세 값을 직접 넣는다. 스프링·2차 움직임은 계속 돈다.
  - 바뀐 것: 처음 불러온 값과의 diff, 전부 되돌리기.
  - C#: `Rig2Motion` 기본값 코드 조각(전체 또는 바뀐 줄만).
- **위쪽**
  - 프로젝트에 저장: `spirit_rig2.json`에 쓴다. 쓰기 전에 `Temp/spirit_rig2.bak.<시각>.json`으로 백업하고, 내용이 같으면 쓰지 않는다.
  - JSON 다운로드, 이 모습 되돌리기, 스크린샷.

콘솔 도구: `rigWeb.seqStrip(name, [[0,"idle"],[0.5,"walk"]], frames, dt)`(동작 전환 띠), `rigWeb.strip(name, motion, frames, dt, {t0})`는 프레임 띠를 `Logs/Screens/<name>.png`로 저장한다. `rigWeb.shot(name)`, `rigWeb.play(m)`, `rigWeb.seek(t)`, `rigWeb.setLook("fire_3")`도 쓸 수 있다.

## 보는 방향 · 무릎 · 오르기 (2026-10-18 추가)

- **무릎**: 다리는 허벅지 → 무릎 → 정강이 → 발목 → 신발이다. 3D 2뼈 IK로 무릎이 앞(+Z)으로 굽는다. 결과를 보는 방향으로 투영하므로, 정면에서는 다리가 짧아지는 것으로, 옆모습에서는 꺾임으로 보인다. `lift`(또는 `legScale`)만큼 다리를 늘이고 몸을 올려 치마 밑으로 무릎이 보이게 한다.
- **방향**: 자세 값 `yaw`가 0이면 정면, 90이면 옆(오른쪽을 봄, 왼쪽은 뒤집기), 180이면 뒤다.
  - 45°·135°를 지날 때 그림이 `look.side`/`look.back`으로 바뀌고, 그 순간 가로로 살짝 좁아진다(`turnPinch`).
  - 정면 그림에서 조금 돈 만큼은 얼굴 층을 옆으로 옮겨 3/4처럼 보이게 한다.
  - 돌아설 때는 `turnTime` 동안 섞는다.
- **방향 규칙(기본안)**: 대기·말하기·반응은 정면, 걷기·나르기는 옆모습, 멈추면 정면으로 돌아선다. 줄기·덩굴 오르기는 옆모습, 사다리는 뒷모습이다. "걸을 때 정면 유지"를 켜면 걸을 때도 정면이다.
- **오르기**(`climb`·`climbDown` 옆, `ladder`·`ladderDown` 뒤): 오른손+왼발, 왼손+오른발이 번갈아 움직인다.
  - 잡은 손과 디딘 발은 가로대(세상)에 고정되어, 몸이 오르는 만큼 내려간다. 내려오기는 같은 동작을 거꾸로 돌린 것이다.
  - 가로대 간격은 `rungGap`·`trunkGap`이고, 화면에 사다리·줄기가 같이 그려진다.
- **옆·뒤 그림이 있는 모습**: 지금은 불 ★3만 있다. 없는 정령은 정면 그대로 걷고 오른다.
- **모션 보기**: 위쪽 "▶ 모션 보기"를 누르면 편집 패널이 숨고 큰 동작 버튼(설명 포함)과 데모 순서 재생이 나온다.

## ★0·★1 버섯 리그 (mush_rig.js)

사람형이 아니어서 따로 리깅했다. 무릎·사람 걷기·옆/뒷모습을 쓰지 않고, 정면 그림에 뒤집기만 쓴다.
- **몸 구조**: 갓 + 대(얼굴) + 작은 발 둘. ★1은 몸 옆의 동그란 손 둘(`nubL/R`)이 따로 움직인다.
  - 손은 `make_parts.py`가 그림에서 원을 찾아 떼어 낸다. 몸통의 손 자리는 주변 색으로 메운다.
  - 갓은 대 뒤에 그린다. 대 윗선은 매끈하게 다듬었고, 주름 구멍은 주름 색으로 칠했다.
- **움직임**:
  - 폴짝 걸음과 뒤뚱(좌우 기울기)이 기본이다.
  - 찌그러짐·늘어남은 부피를 유지하는 젤리 스프링으로 처리한다.
  - 갓은 몸보다 늦게 따라와 출렁인다(진자 + 세로 출렁). 착지 때 갓이 눌렸다 튄다.
  - ★1은 손을 파닥이고, ★0은 손 흔들기를 몸 흔들기로 대신한다.
- **동작 이름**: 사람형과 같은 이름을 모두 지원한다(게임이 같은 상태를 넘긴다). 나르기는 갓 위에 바구니(`Rig2/prop_basket`)를 인다. 사다리·줄기는 폴짝폴짝 한 칸씩 튀어 오른다.
- **상수**: JSON `"mushMotion"`에 저장된다. 웹의 동작 상수·C# 탭이 모습에 따라 바뀐다.

## 움직임 구조 (rig2.js → C#)

1. 동작 함수 `Pose<동작>(t, p)`가 목표 자세 `Rig2Pose`(`POSE_KEYS`)를 만든다. 대기 중에는 짧은 행동(fidget)이 겹쳐진다.
2. 동작이 바뀌면 `blend`초 동안 이전 자세에서 섞는다.
3. 골반·상체·팔은 스프링(k, 감쇠비 z)으로 따라간다. 팔꿈치가 어깨보다 늦게 따라와서 동작이 겹친다.
4. 2차 움직임은 진자다. 머리카락(정수리 축), 치마(허리 축), 손(손목), ★0·★1 갓이 그 관절점의 실제 가속도로 흔들리고, 무게가 아래를 향한다.
5. 다리는 IK다. 발목 목표는 root 공간(땅)에 있고, 디딘 발은 이동 속도로 뒤로 미끄러져 땅에 붙어 보인다. 골반 높이는 디딘 다리 길이로 정해진다(역진자).
6. 표정: 동작이 정한 얼굴에 깜빡임(가끔 두 번)이 더해지고, 누르면 놀람 → 웃음으로 바뀐다.

그리는 순서(sortingOrder, 뒤→앞): 뒷머리 -80 · 먼 쪽 팔 -70~-50 · 다리 -30 · 신발 -20 · 치마 0 · 가슴 10 · 머리 40 · 얼굴 50 · 팔 80~100 · 목 프릴 120. 걸을 때는 앞으로 나온 발이 앞에 그려진다.

MORE MUST MUSH — "Flat storybook" visual guide for backgrounds and UI (resource_test branch).
DRAWING STYLE (from the AMELAB picture-book poster the user shared; copy only its drawing technique, NOT its dark night mood):
- Flat, simple graphic shapes like a modern children's picture book: each area is one flat color with a subtle fine grain / risograph print texture; shading is just one flat darker or lighter shape, no gradients, no glossy highlights, no 3D rendering.
- No outlines, or only a very thin darker edge of the same hue. Shapes are simplified, rounded and slightly naive; foliage is built from simple repeated leaf / blob shapes; few details.
COLORS (from the attached sunny references: round red-capped critter, blue sky hills, game logo):
- Bright, clear, cheerful daytime palette: sky blue, fresh leaf greens, butter yellow, warm cream, coral red, candy pink, soft mint, warm light browns. Shadows are slightly deeper, cooler versions of the base color, never black or grey.
GENERAL:
- Backgrounds stay calm and lower-contrast in the play / content areas so the existing bright sprites and UI on top stay readable.
- No text, no labels, no frames unless asked.

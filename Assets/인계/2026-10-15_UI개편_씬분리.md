# 2026-10-15 UI 개편 — 씬 4개 분리 · 배치한 UI에 기능만 연결

## 인계 블록

- **[목표]** 사람이 배치한 캔버스에 코드는 기능만 잇는다 (**코드로 UI 생성 금지**). 씬은 MainMenu(시작) → MainGame(업그레이드) → OutGame(세계수) → Stage(라운드) 4개. 찾기는 Awake에서 이름으로 한 번만.
- **[현황]**
  - MainMenu · MainGame(공방·도감 팝업 포함) · OutGame 캔버스는 배치된 버튼 전부 연결 끝. 플레이로 확인함.
  - Stage 씬은 RoundView 배치 전이라 미완.
  - 앞부분(App·씬 흐름·MainMenu·공방·글자 넘침·언어 폰트)은 사용자가 `ed6b8aa [MOD] UI 와이어 수정중`으로 커밋함. **도감·세계수 연결은 미커밋.**
- **[반환]** 아래 "남은 일"의 UI가 배치되면 같은 방식으로 연결한다. 사용자 결정 대기 1건("가득차면 배치" 뜻).

## 다음 세션 시작점

1. 사용자가 배치하면 연결: 옵션 창 · 초기화 확인 창(MainMenu) · 알림 창(토스트) · OutGame 탭 내용 창 · OutGame→MainGame 돌아가기 버튼.
2. MainMenu의 임시 창 코드(`MainMenu.cs` `BuildDialog`) 삭제 — 확인 창·옵션 창이 배치된 뒤.
3. Stage 씬: RoundView·라운드 HUD 배치 후 `StageController`에 연결.
4. 공방 번역("Craft Shop"이 어색하다는 의견) — 아직 DB 안 바꿈.

## 이번 세션 후반 (미커밋)

### 도감 (`MushDexPopup.cs`, MainGame)
- MushDex 창 위치·크기를 공방(Harvesters) 창과 같게 맞춤 (씬 저장).
- 탭 `Button_Mush_1~4` = 식용 · 약용 · 독버섯 · 꼬마.
- 카드(`Mush_Dex_Group` 자식, 화면 위치 순): 등록(처음 수확)한 종만 처음 딴 라운드 순 → 같은 라운드는 도감 번호 순으로 앞부터 채움. 빈칸은 비우고 안 눌림. 꼬마는 세계수 합류 순. 15칸 넘으면 카드 위 마우스 휠로 한 줄씩.
- 상세 창(MushDex/Image): 이름 · 등급·분류 · 그림 · 별 5개 · 설명(특징+특성) · 기록(다음 별·별 능력·처음 딴 라운드·누적·해금 조건). 기록 글은 길이만큼 늘이고 ScrollBar·휠로 내림. 창에 RectMask2D를 붙여 넘친 글을 가림.
- 창 안의 `Exit`는 이름만으로 닫기에 연결됨.

### 세계수 (`OutGameController.cs`, OutGame)
- `UP_Panel`: Gold·수확석 안 글자 = 골드·균사석(`G.gem`), 바로 아래 `Text (TMP) (1)` = `보관 m:ss / h:mm:ss` (+가득!), 1초마다 갱신.
- 수확 보따리: 씬에서 `Panel/Image`를 **`Button_Bag`으로 이름 바꾸고 Button 추가**(씬 저장). 쌓인 게 있을 때만 눌림 → `BagClaim`.
- `Down_Panel`(접힘) ↔ `Down_hidden_Panel`(펼침) 누르면 서로 바뀜. 접힌 상태로 시작. 펼침 9칸 = 합류한 꼬마(합류 순), 나머지는 배치한 "?" 그림.
- `Button_Group` 4개 = 성장 · 꼬마 · 공방 · 꾸미기 임시 탭 (고른 탭만 눌린 모양, 내용 없음).
- FarmView(꼬마가 돌아다니는 월드)는 씬에 없음 → 경고 로그만. 보따리는 시간으로 계속 쌓임.

## 확인 필요 / 알려진 것
- **"가득차면 배치"** 뜻이 불분명: 지금은 보따리 창 항상 보임 + 쌓인 게 있을 때만 눌림. "가득 찼을 때만 창이 나타남"이면 바꿀 것.
- 알림(App.Notify) 표시 UI가 없어 로그로만 나옴.
- 옵션 버튼: MainGame은 창이 없어 경고만, MainMenu는 코드로 만든 임시 창(규칙 위반, 배치 후 삭제).
- 러시아어에서 좁은 칸(도감 "약용" 탭 등)은 글자가 많이 줄어듦.
- `Assets/Resources/Image/7105071.png`·`chest.png`, `ONEMobilePOP SDF.asset`, 씬 변경 일부는 사용자가 넣은 것.
- 테스트는 에디터 세이브(PlayerPrefs)를 스크래치에 백업 → 가짜 데이터로 확인 → 되돌림. 언어 설정도 en으로 되돌림.
- 플레이 모드에서 프레임이 안 넘어가 `Start`가 안 불리는 경우가 있어 테스트는 리플렉션으로 `Start` 호출.

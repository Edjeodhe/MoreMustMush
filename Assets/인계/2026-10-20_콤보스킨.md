# 2026-10-20 콤보 스킨 — 메이플식 그림 숫자 콤보 · 치명타 연출 · 가운데 SUPER COMBO!

먼저 읽을 것: 이 파일 → [RoundView.Combo.cs](../Scripts/View/RoundView.Combo.cs)

## 인계 블록
- **[목표]** 인게임(Stage 라운드) 콤보를 데미지 스킨처럼 그림 숫자로 튀어 오르게. 치명타는 더 크게·펀치·흔들림·빛 번짐·잔상·반짝이. 피버가 켜질 때 화면 가운데에 "SUPER COMBO!"가 크게 꽂혔다가 커지면서 사라짐.
- **[현황]** 그림·코드·프리팹·씬 연결 끝, 컴파일 오류 없음, 플레이 스크린샷 1차 확인함(일반·치명타·배너 모두 뜸). 1차 확인에서 나온 문제(빛 번짐 너무 큼, 고리 너무 큼, COMBO 글자 작음)는 **고쳤지만 고친 뒤 플레이 확인은 못 함** — 사용자가 "일단 스탑"해서 멈춤. 일부 파일은 사용자 커밋 `6379827`(전체 리소스 수정)에 이미 들어감, 나머지 미커밋.
- **[반환]** 고친 뒤 화면을 다시 찍어 사용자에게 보여 주고(아래 확인 방법), 크기·위치를 다듬은 다음 사용자 확인 → 커밋.

## 사용자 결정 (2026-10-20)
- 피버 표시는 "피버 자리에 SUPER COMBO!": 시뮬의 피버(1.5초 안 연속 수확 25 → ×1.5, 70 → ×2)가 켜지는 순간 가운데 배너. 점수 보너스는 그대로. 1단계 = 금색, 2단계 = 치명타 색.
- (참고) 시뮬의 원래 "SUPER COMBO!"는 연속 10000마다라 사실상 안 뜸. 피버 글자(FEVER!)는 Unity 화면에 원래 아무 표시도 없었음.

## 한 일
- **그림** (Codex, `Tools/art/sheets-dream.mjs`에 시트 2개 추가, `node Tools/art/build-art.mjs --set dream combo_skin combo_banner`)
  - `combo_skin` 5×5 → `Resources/Art/Dream/UI/Combo/`: `n0~n9`(꿀색 금빛, 밤색 테두리), `c0~c9`(분홍·진홍 + 금 테두리 + 반짝이), `combo_n`·`combo_c`(COMBO 글자), `critical`(CRITICAL!). 기존 데미지 숫자(`digits`)와 같은 서체.
  - `combo_banner` 1×2 → `super_combo_n`·`super_combo_c` (두 줄 SUPER / COMBO!).
- **글자 에셋**: 메뉴 `MoreMush/Build Combo Digit Sprite Asset` → `Resources/Sprite Assets/ComboDigits.asset` + `Fonts/ComboDigitsAtlas.png`. 금·치명 세트를 각각 중앙값 숫자 높이로 맞추고 COMBO 글자는 1.3배. 기존 데미지 숫자 빌더와 아틀라스 굽는 부분을 `PackSpriteAsset`로 합침(DmgDigits 다시 구워 바이트 동일 확인).
- **시뮬** (`RoundSim`): `ComboPop`(RoundTypes) + `R.combos`. `Damage()`에서 직접 타격(kind "direct")마다 `Combo(b, m, crit)` — 수확기 하나에 하나, 2타부터, n = `b.hits`(HUD 콤보와 같은 값), 맞힌 버섯 오른쪽 위. `COMBO_LIFE` 1.15초, 위로 천천히 뜬다. `FeverMsg.n` = 그때 연속 수 추가.
- **화면** (`RoundView.Combo.cs`, RoundView를 partial로): 프리팹 복제 슬롯 풀(`ComboPopSlot`).
  - 일반: easeOutBack로 톡, 잔상 1번, 옅은 금빛 번짐, 살짝 기울기.
  - 치명타: 1.6배, 펀치 스케일(2.1배에서 내리꽂혀 출렁), 흔들림, 분홍 빛 번짐, 고리 터짐, CRITICAL! 글자, 반짝이 3개.
  - 배너(`feverMsg`): 0.2초 2.8배→1배 꽂힘 → 출렁·숨쉬기 → 1.15초부터 1.7배로 커지며 사라짐, 잔상·고리·빛·반짝이 4개, 아래에 "25 COMBO".
  - 콤보 숫자 크기: 34 + log2(n)×4 (최대 +18), 치명 ×1.6.
- **프리팹** (Unity MCP execute_code로 만듦): `Prefabs/Round/ComboPop.prefab`(Body/Glow·Ring·Ghost·Num·Tag·Spark0~2), `ComboBanner.prefab`(Body/Glow·Ring·TagGhost·Tag·Num·Spark0~3). 빛=FX/soft, 고리=FX/ring·impact_ring, 반짝이=FX/twinkle.
- **씬**: `Stage.unity` RoundView에 `comboPrefab`·`comboBannerPrefab` 연결(2줄). OutGame 씬이 저장 안 된 변경(다른 세션 것일 수 있음)으로 열려 있어서 Stage를 추가로 열어 Stage만 저장하고 닫음 — OutGame은 건드리지 않음.
- **HUD**: `StageHUD` 오른쪽 위 Combo 숫자도 금색 스킨 숫자로, 오를 때마다 톡 튐. **아직 화면 확인 안 함** (칸 크기에 맞는지 볼 것).

## 2. 안정성 (세이브·시간)

- **세이브 로드 실패 시 덮어쓰기 방지 (`Save.cs`).** 예전에는 읽기에 실패하면 새 게임을 만들고, 다음 저장 때 원래 세이브를 덮어썼다.
  - 이제는 원문을 `mushroomPinball_save_v2_bad`에 따로 남기고 "세이브를 읽지 못해 새로 시작해요" 토스트를 띄운다.
  - 저장 예외는 잡아서 로그만 남긴다(WebGL 용량 초과 등).
- **`SaveIO.Sanitize`:** 빈 딕셔너리, 음수 레벨·판 수, NaN 재화, 잘못된 의뢰, null 도감 항목, 건물 `nextUid` 충돌을 정리한다. 올바른 세이브에는 아무 변화가 없다.
- **`SaveIO.Suspended`:** 밸런스 봇(`BalanceSim.Sandbox`)이 도는 동안에는 실제 세이브 키에 쓰지 않는다. 중간에 끊겨도 개발 세이브가 남는다.
- **`Game.FixClock`** (`AutoEnsure`에서 호출): 기기 시계가 뒤로 돌아가 미래 시각에 멈춘 타이머를 지금 기준으로 당긴다. 대상은 자동 수확, 나무 버섯, 건설, 부탁이다.
- **WebGL 저장 시점:** 포커스를 잃을 때도 저장한다(WebGL은 `OnApplicationPause`가 오지 않음).
- **알 수 없는 버튼 액션 경고:** `GameFlow`의 default case에서 경고 로그를 남긴다. 예외는 `dbg-*`와 `"none"`이다.
- **기타:** 숫자 파싱을 InvariantCulture로 통일했다(`shopq`, `buyspore`). 짓는 꼬마가 없는 건물은 `AccelPanel`에서 "꼬마"로 표시한다.

## 3. 최적화 (결과는 그대로, 할당·네이티브 호출만 줄임)

**밸런스 봇이 지나가는 코드.** 난수 순서와 계산 순서는 그대로다. 1번 대조로 확인이 필요하다.
- `RoundSim.QueryCircle`: 결과 리스트를 스택 풀로 재사용한다(`FreeQuery`). 모든 호출 지점에서 루프가 끝난 뒤에 돌려준다.
- `StepBall`:
  - `b.inside`와 `b.insideNext`를 번갈아 쓴다.
  - 젤리 버퍼 `jellyBuf`를 재사용한다.
  - 두더지 굴의 배열 생성을 없애고 `MoleWarp`로 뺐다.
  - 도토리 `All()`을 직접 비교로 바꿨다.
- `SimFrame`과 `UpdateEffects`: `balls`, `waves`, `tornados`, `shrooms`의 `ToList()`를 시작 개수만큼 도는 인덱스 루프로 바꿨다. 루프 안에서는 항목이 더해지기만 하고 빼기는 루프 뒤 `RemoveAll`에서만 일어나므로 같은 결과다.
  - 지연 큐는 비어 있으면 건너뛴다.
  - `skillFlash`는 키 목록(`flashKeys`, `Flash()`)으로 돈다.
- `Harvester.ab`: 별 등급별 결과를 메모이즈한다(읽기 전용으로 쓸 것).
- `U.Hex`는 파싱 결과를 캐시하고, `U.PickWeighted`는 버퍼를 재사용한다.
- `Game.CodexCount`와 `GoldenCount`는 LINQ 대신 루프로 센다. `PriceMul(ab)` 오버로드를 추가했다.
- **주의:** `Snd.Hit()`의 `Random.Range`는 헤드리스에서도 난수를 소비한다. 절대 건너뛰지 말 것.

**화면 (봇과 무관)**
- **`RoundView`:**
  - 필드 글자는 사라질 때까지 같은 TMP를 쓴다. 투명도는 `canvasRenderer` 알파, 튀어나오는 크기는 `scale`로 바꿔 메시를 다시 만들지 않는다.
  - 선은 `SetPositions`와 재사용 버퍼로 그린다.
  - 고리는 최근 64개만 그린다.
- **`RoundHUD`:** 라운드마다 바뀌지 않는 글자는 라운드 시작 때 한 번만 만들고, 숫자 글자는 값이 바뀔 때만 다시 만든다. `GetComponent`와 `GetChild`는 캐시한다. `ComboHUD` 글자도 캐시한다.
- **하위 Canvas:** `UIUtil.SubCanvas`로 필드 글자층과 피버 불꽃층에 런타임에 하위 Canvas를 붙인다. 씬에 직접 달면 더 좋다.
- **`TreeNodeView`:** 상태(상태·레벨·hover·이름표 표시)가 바뀔 때만 선, 레벨 칸, 속 그림, 이름표를 다시 그린다. 자식 오브젝트는 숨김 상태가 바뀔 때만 켜고 끈다. 예전에는 노드 108개가 매 프레임 TMP를 켰다 껐다 했다.
- **`TreeTooltip`과 `TreeView`:** 툴팁은 바뀔 때만 다시 만든다. 프레임마다 돌던 LINQ를 없앴다.
- **농장:**
  - 짓는 건물 찾기를 루프로 바꿨다(`ActiveBuild`).
  - 버섯 딸 때 저장은 1.5초 모았다가 한 번에 한다(`SaveSoon`, `Flush`에서 바로 저장).
  - `CritterRig`의 모습 비교에서 문자열 결합을 없앴다.
  - 스프라이트 키는 `SpriteDB.Get(prefix, name)` 캐시를 쓴다.
  - 건설 타이머는 초가 바뀔 때만 다시 그린다.
  - 배치 바는 바뀔 때만 다시 그린다.
  - `SetActive`는 상태가 바뀔 때만 호출한다.
- **기타:**
  - `Art.SetFx`는 셰이더 속성 id를 캐시한다.
  - `UIUtil.Ic` 태그를 캐시한다.
  - `Snd`의 지연 소리를 클로저 없이 처리하고, 스킬 키를 캐시한다.
  - `BuyMax`(연속 구매)는 저장을 한 번만 한다.
  - `UIButtonFx`는 값이 바뀔 때만 쓴다.
  - `Spark`는 `Image`를 캐시한다.
  - `targetFrameRate=60`은 WebGL에서 쓰지 않는다(브라우저 rAF에 맡김).

## 참고

- 컴파일 검사 방법: csproj가 오래돼서(삭제된 `TaxScreen.cs`를 아직 포함), 와일드카드로 `Assets/Scripts/**`와 `Assets/Editor/**`를 잡는 임시 프로젝트로 `dotnet build`를 돌렸다. Unity를 열면 csproj는 다시 만들어진다.
- Python으로 C# 파일을 고칠 때는 CRLF를 유지해야 한다. 이 세션에서 한 번 `Game.cs`가 LF로 바뀌었다가 복구됐다.

# 261016 PV 마무리 인계

브랜치 KHD-Teset. 커밋은 사용자 확인 뒤에만. 보고는 한글.

## 사용자 결정
- PV는 지금 콘티(`Marketing/PV/PV_콘티.md`) 그대로 간다.
- 레퍼런스(NKK) PV와 차별점 두 가지를 넣는다:
  1. **타이틀 뜰 때 무기로 쳐 내기**: 엔드카드(27.0초~) 로고가 그냥 팝 하지 않고, 수확기 무기(낫 `Harvesters/sam.png` 등)가 날아와 로고를 "쾅" 쳐서 제자리에 박히게 한다(게임의 '튕겨 치기'와 같은 동작). 충격 번쩍임·흔들림·튕겨 나가는 무기, 27.3초 쯤 큰 "bonk" 효과음.
  2. **마지막에 정령 손 흔들기**: 엔드카드 정령들이 통통 튀는 대신 손을 흔들며 인사.
- 음악은 사용자가 Gemini로 만든다(프롬프트는 대화창에 줌). 지금은 스크립트 합성 음악 그대로.

## 지금까지 (Tools/pv/build_pv.py)
- 녹화 프레임 전부 있음: `Temp/pvcap/round(541) tree(168) farm(152) boss_king/cleaner/phantom(150)`. farm은 21:21 녹화라 세계수 수정 전(나무에 작은 옛 버섯 덩어리, 돌아가기 팻말 없음).
- 손 흔들기용 리그 조립 함수 추가함: `evo_look` · `evo_part` · `_put` · `_rot` · `_arm` · `kid_wave_frame(kind, q)` · `paste_kid_wave(dst, kind, cx, foot_y, t, scale)`.
  - 게임 리그 `Assets/Resources/Rig/evo_rig.json` ★2(사람 모양 정령, 위팔/아래팔 분리)를 그대로 조립. 층 순서: 뒷머리 → 다리 → 몸 → 머리·얼굴 → 팔 → 목 프릴(게임 sortingOrder와 같음).
  - 조립 자체는 정상(시험 그림 확인). **흔드는 팔 각도 다듬는 중**: 팔이 짧아 높이 들면 머리 옆 뺨에 붙어 보였다. 지금 값 `_arm(layer, l, 1, 98 + 6*sw, 68 + 32*sw)`(위팔 옆으로, 아래팔 세워 흔들기) 결과는 아직 못 봄.
  - ★2가 있는 정령: dew fire leaf moon rock spark star wind.
  - 시험 스크립트: `Tools/pv/rigtest.py <출력.png>`(5종 × 2위상), `Tools/pv/armdbg.py <출력.png>`(팔 각도별 관절 디버그).
- `s13_end`는 아직 옛 방식(로고 팝 + `kid()` 통짜 정령 hop). 여기에 1·2를 넣어야 함.

## 음악 (사용자가 Gemini로 만든 곡, 22시 이후 추가)
- `Marketing/PV/art/The_Bramblewood_Picnic.mp3` (59.7초, 44.1kHz 스테레오). 합성 음악(`synth_audio`) 대신 이 곡을 쓴다.
- 곡 흐름(2초 단위 음량): 0~2초 무음, 4~22초 잔잔→점점, **24.5~26.2초 거의 무음(곡이 비는 곳)**, 26초부터 크게, 32~50초 가장 큼, 52초부터 잦아듦.
- 제안 정렬: **곡 6.0초부터 30초 사용** → 곡의 빈 곳이 영상 18.5~20.2초(보스 "Uh-oh...")에, 곡이 다시 터지는 26초가 영상 20초("BOSS!!")에 온다. 끝(영상 29~30초)은 0.8~1.2초 페이드아웃.
- 효과음(무기 휙·27.3초 bonk·글자 팝)은 곡 위에 얹는다. 곡보다 너무 크지 않게.

## 마무리 (22시, 완료)
- 손 흔들기: 흔드는 팔만 1.4배·어깨 0.1 바깥으로(`_arm`의 k·out), `_arm(layer, l, 1, 96 + 4*sw, 52 + 20*sw, 1.4, 0.1)`. 왼쪽 정령은 뒤집어 바깥 손을 흔든다.
- `s13_end`: 27.0 낫이 돌며 날아와 27.3 로고 왼쪽 아래를 쾅 → 로고 찌그러졌다 튀며 박힘, 번쩍·흔들림·충격선, 낫은 왼쪽 위로 튕김. ★2 정령 4명(leaf·fire·dew·star) 손 흔들기. 글자 y 745.
- 소리: `make_audio` — 곡 6.0초부터 30초, 끝 1.1초 페이드, 효과음(pv_sfx.wav)을 amix + 리미터. 27.0~27.85 곡을 낮춰(duck) bonk가 들리게. `--audio-only`로 영상 다시 안 뽑고 소리만 교체.
- 결과: `Marketing/PV/out/MoreMustMush_PV_30s.mp4` (1920×1080, 30.0초, 새 farm 녹화 21:46 반영).

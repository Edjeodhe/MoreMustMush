## 옵션 · 다국어
- 옵션 창: 타이틀·균사 트리(왼쪽 버튼)·일시정지에서 열림. 언어 / 소리(저장됨) / 라운드 끝내고 정산(라운드 중) / 타이틀로(라운드·타이틀 밖)
- `Core/Loc.cs`: 키는 한국어 원문. `Loc.T("원문")`, `Loc.F("버섯 {0}개", n)`. 언어는 PlayerPrefs `mmm_lang`, 첫 실행은 기기 언어
- 번역표 `Assets/Resources/Loc/strings.txt` (TSV, 첫 줄 `ko en ja`, 칸 안 줄바꿈은 `\n`). **`.tsv`는 Unity가 TextAsset으로 안 읽어서 `.txt`로 둠**
- 데이터 이름은 번역 속성: `nKo`(원문, 검색·비교·키) / `n`(화면용). 이름으로 찾는 곳은 반드시 `nKo`
- 씬 글자: `UI/LocText`(역할 Title/Body + 외곽선 프리셋 + 원문 키). 언어가 바뀌면 폰트를 바꾸고 원문 그대로인 글자만 번역
- **언어 추가 방법:** `Loc.LANGS`·`LANG_NAME`에 코드 추가 → `strings.txt`에 열 추가 → `Editor/LocTools.FONT_SETS`에 폰트 세트 추가 → 메뉴 1·4 실행. 옵션의 언어 버튼은 자동으로 늘어남

### 에디터 메뉴 `MoreMush/다국어/`
1. 폰트 에셋 만들기 — TTF → SDF 에셋, 대체 폰트(제목: KR 제목 → 같은 세트 본문 → ONE Mobile Regular), 외곽선 프리셋 3종, `Resources/Loc/LocFonts`
2. 씬 글자 연결 — 모든 TMP에 LocText 부착 (이미 실행, 씬 2347개)
3. 번역표 갱신 — 소스 한국어 리터럴 + 씬 키를 모아 `strings.txt` 갱신(있던 번역 유지). 보간 문자열에 한국어가 남으면 알려 줌
4. 폰트 굽기 — 언어 열별로 필요한 글자만 정적 아틀라스로 (WebGL 메모리)

## 폰트
| 언어 | 제목 | 본문 |
|---|---|---|
| KR | ONE Mobile POP | ONE Mobile Regular |
| EN | ONE Mobile POP | LINE Seed Sans Rg |
| JP | LINE Seed JP Eb | LINE Seed JP Rg |
- ONE Mobile Regular가 한글·가나·한자 4622자를 다 가져서 만능 대체 폰트
- **ONE Mobile 폰트는 라이선스 파일이 같이 오지 않았음** — 배포 전 확인 필요. LINE Seed는 OFL(`Assets/Fonts/LINESeed-OFL.txt`)
- 예전 Jua·Noto Sans KR 파일은 지우지 않고 남김(씬은 더 이상 안 씀)

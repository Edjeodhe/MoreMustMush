## 4. Unity MCP 연결 (이번에 바꾼 것)

### 4-1. 설정
- 이 PC의 전역 `mcp-unity`(`~/.claude.json` 최상위 `mcpServers`)는 **다른 프로젝트(WeedHoldings)의 서버**를 가리킨다. 이건 그대로 뒀다.
- MoreMustMush 프로젝트 항목(`projects["C:/Project/MoreMustMush"].mcpServers`)에 `mcp-unity`를 추가했다: `{"type":"http","url":"http://127.0.0.1:8080/mcp"}`. 이게 전역 설정보다 우선한다.
- 백업: `~/.claude.json.bak_20261019_170742`. 되돌리려면 이 파일로 덮어쓴다(그 사이 다른 설정을 바꿨다면 `mcpServers` 항목만 지운다).
- 이 프로젝트의 Unity 쪽 패키지는 `com.coplaydev.unity-mcp`(MCP for Unity)다. 옛 연결(`com.gamelovers.mcp-unity`)과는 도구 이름과 인자가 다르다. WeedHoldings의 서버를 이 프로젝트에 쓰지 않는다.

### 4-2. 켜는 순서 (에디터를 열 때마다)
1. Unity에서 MoreMustMush를 연다(Hub 로그인 상태여야 한다. 배치 모드는 라이선스 문제로 막혔었다).
2. `Window > MCP for Unity` (Ctrl+Shift+M) → Transport **HTTP Local** → **Start Server**(`Stop Server`로 바뀌면 켜진 것) → **Start Session**/**Connect**(상태 점 초록).
3. `uv`를 못 찾으면 `C:\Users\user\AppData\Local\hermes\bin\uvx.EXE`를 지정한다. 서버가 안 뜨면 `Show Debug Logs`를 켜고 콘솔의 `MCP-FOR-UNITY` 로그를 본다.
4. 확인:
   ```bash
   node Tools/unity-mcp.mjs tools                              # 도구 목록이 나오면 서버 OK
   node Tools/unity-mcp.mjs call manage_scene '{"action":"get_active"}'   # 에디터 응답 확인 (MainGame 씬이 나와야 함)
   ```
- 2026-10-19 17시경 이 방식으로 확인했다: 서버 `8080`(python) 켜짐, 활성 씬 `MainGame`, 콘솔 오류 없음.

### 4-3. 새 세션에서 쓰는 법
- MCP 설정은 세션을 시작할 때만 읽는다. **새 세션에서는 `mcp__mcp-unity__manage_scene` 같은 도구가 바로 보여야 한다.** 보이지 않으면 서버가 꺼져 있거나(4-2) 세션이 설정을 읽기 전에 열린 것이다.
- 도구가 안 보이거나 응답이 없을 때의 우회: `Bash`로 `node Tools/unity-mcp.mjs call <도구> '<json>'`, C#은 `bash Tools/uexec.sh < 파일.cs`. 인자는 `node Tools/unity-mcp.mjs describe <도구>`로 확인한다.
- 이번에 옛 연결에서 `get_play_mode_status` 한 번이 **30분(1800초)** 응답 없이 대기했다. 새 세션에서도 MCP 호출이 오래 걸리면 중단하고 4-2를 다시 확인한다.
- 메뉴 실행 예(폰트 굽기): `node Tools/unity-mcp.mjs call execute_menu_item '{"menu_path":"MoreMush/다국어/4 폰트 굽기"}'` — 인자 이름은 `describe`로 먼저 확인한다.

### 4-4. 주의 (기존 인계에서 가져온 것)
- 에디터로 보내는 C#에 **한글을 넣으면(주석 포함) 조용히 실패**한다. 영어로만 쓴다.
- 긴 작업 중에 다른 MCP 호출을 겹쳐 보내면 끊길 수 있다. 하나씩 보내고 기다린다.
- 컴파일·도메인 리로드 중에는 잠깐 끊긴다. 에디터가 배경에서 멈추면 플레이 검증 동안만 `Application.runInBackground`를 켠다(영구 설정은 바꾸지 않는다).
- 에디터가 프로젝트를 잡고 있는 동안은 같은 프로젝트에 `-batchmode` Unity를 못 돌린다.

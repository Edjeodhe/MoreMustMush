# 2026-10-26 세계수 휠·꼬마 짚기 손 확인 + 8단계 장식 크기를 나무 배율에 맞춤

먼저 읽을 것: 이 파일 → [2026-10-26_세계수휠줌_점검.md](2026-10-26_세계수휠줌_점검.md)

## 인계 블록
- **[목표]** 사용자: KHD-Teset 플레이로 휠 줌·휠 끌기·꼬마 짚기 같이 점검 + "나무 크기 키운 만큼 나무에 올라가는 객체 위치도 맞게 조정".
- **[현황]** 휠 줌·꼬마 짚기(마우스 올리기)는 손으로 확인됨. 장식 크기를 8단계 그림 배율(1.15)에 맞춤. 미커밋.
- **[반환]** 사용자: 휠 끌기·꼬마 누르기(클릭)·아래 꼬마 칸 확대를 한 번 더 손으로 확인.

## 손 확인 (사용자 조작, 콘솔 감시 기록)
- 휠 줌: ViewK 0.557 ~ 1.200(최대 축소) 오감, 굴린 곳 쪽으로 화면 가운데가 따라감 → 됨.
- 꼬마 짚기: 마우스 올리기(hover)가 8마리 모두 잡힘(leaf·star·moon·spark·wind·fire·dew…) → 그림 전체 사각형 판정 됨.
- 기록에 없던 것: 줌 없이 화면만 움직인 기록(휠 끌기), 꼬마 클릭(pokeAt), 꼬마 칸 확대(FocusedKid). 안 해 본 것인지 안 된 것인지 모름 → 다시 확인 필요.

## 8단계 나무 위 객체
- 자리(정령 길·머무는 곳·나무버섯·장식 자리)는 도면 비율(UV) × `WT.width`라 이미 같이 커짐. `fit_spots.py --dry 7`(새 너비 2193 기준): 고칠 것 없음(8 spots / 8 spirits, 겹침·발판 길이·손 닿기 모두 통과).
- 장식 크기만 고정 px(95·115 × 화각)라 상대적으로 작아졌음 → `WT.grow` 배열 추가(8단계 1.15), `FarmTreeView.DecoK = 화각 × grow`로 장식 크기·빈 장식 칸 짚기 범위에 곱함. 걸이형 249px 확인.
- 도구도 같은 값: `tree_defs.py`(GROW, deco_px), `serve.mjs`(/api/defs grow), `app.js`(decoPx).
- 정령 크기·화각은 그대로(지난 세션 사용자 결정). 플레이에서 정령이 발판·가지·버섯 계단 위에 제대로 섬.
- 스크린샷: `Assets/Screenshots/tree8_deco_grow_after.png`, `tree8_spirits_on_tree.png`.
- 주의: `install_tree_stages.py`가 찍는 `WT.width`를 다시 붙이면 8단계 1907로 돌아가는데 `grow`는 1.15로 남음 → 둘을 같이 고칠 것.

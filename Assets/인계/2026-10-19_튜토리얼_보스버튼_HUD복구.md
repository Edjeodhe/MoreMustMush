## 작업 요령·주의
- **Unity MCP**: 에디터 안 MCP for Unity 서버(`localhost:8080/mcp`, v3.4.8)는 켜져 있지만 **Claude 세션에 등록돼 있지 않다**(`~/.claude.json`의 `mcpServers` 비어 있음, 프로젝트 `.mcp.json` 없음). 이번에는 HTTP JSON-RPC를 직접 불렀다(initialize → `mcp-session-id` 헤더 → `tools/call`). 등록하면 바로 도구로 쓸 수 있다.
- **에디터에 포커스가 없으면 플레이 중에도 게임 루프가 멈춘다**(`Time.frameCount` 1에서 정지, `Application.runInBackground` false). 이때 띄운 UI는 다시 그려지지 않아 스크린샷에 안 보인다. 확인할 때만 `execute_code`로 `Application.runInBackground = true`(실행 중 값이라 저장 안 됨).
- 실행 중에 붙인 하위 `Canvas`(overrideSorting)는 그림이 등록되지 않았다(depth −1). 임시 창은 하위 캔버스 없이 루트 캔버스의 마지막 자식으로 둔다. MainMenu 루트 캔버스 정렬은 10000.
- 테스트 부작용: Stage를 바로 플레이해 라운드를 몇 번 시작·끝냄(에디터 세이브 기록). 언어는 테스트 중 바꿨다가 `mmm_lang = ko`로 되돌림. 플레이 중 Unity가 바꾼 `GowunBatang-Bold Wood.mat`은 되돌림. 스크린샷(`Assets/Screenshots`)은 지움.

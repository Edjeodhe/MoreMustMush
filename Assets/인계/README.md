# 인계

작업 세션이 끝날 때마다 다음 에이전트(또는 다음 세션)에게 넘기는 인계 파일을 여기에 쌓는다.

## 규칙

- 파일 하나 = 세션 하나. 이름은 `YYYY-MM-DD_주제.md` (같은 날 두 번이면 `_2`를 붙인다)
- 지난 파일은 고치지 않는다. 새 파일을 추가하고 아래 목록 맨 위에 한 줄을 넣는다
- 내용이 다음 세션에 덮인 파일은 `지난/`으로 옮긴다(내용은 그대로). 지금 기준 요약은 `요약_밸런싱_DB.md` — 밸런싱·DB 상태가 바뀌면 이 요약을 고친다
- 각 파일 맨 위에 인계 블록([목표][현황][반환])과 "다음 세션 시작점"(할 일 순서)을 둔다
- 진행 중인 현황 기록은 프로젝트 루트 `문서.md`다. 세션을 끝낼 때 그 내용을 여기에 날짜 파일로 남긴다

## ★2·★3 공용 맨몸 틀 구조 (2026-10-16 오후, 이 구조가 아래 "예전 부품 시트" 방식을 대체)

시트에 부품 12개를 몰아 그리면 칸이 빠져서(새싹·바람 4칸씩 빠짐), **부위별로 한 장씩** 뽑고 **복장은 정령끼리 공용**으로 바꿨다(사용자 확정).
- **층 (뒤→앞):** 뒷머리 → 다리(신발 포함, 복장 부품) → 몸통+드레스(한 장) → 머리(갓·얼굴·앞머리 한 장, 얼굴은 떼어 표정 층) → 팔(위팔/아래팔 공 관절, 두 팔 다 앞) → 목 프릴(collar, 어깨 관절을 덮음).
- **공용 그림:** `Characters/EvoKit/kit_base_<★>`(마네킹), `kit_body_<★>_torso`, `kit_outfit_<gill|pick|climb|carry>_<★>_dress`, `kit_outfit_gill_<★>_leg`.
  - 팔 `kit_body_<★>_arm`은 생성기 안전 필터에 계속 막혀서 예전 `e_fire_3_arm`을 복사해 ★2·★3 공용으로 쓴다(★2는 리그가 크기를 줄임).
- **정령별 그림:** `kit_<id>_<★>_head`, `kit_<id>_<★>_hair`. ★2 뒷머리는 턱선 단발로, 4칸 시트 `kit_hair2_a·b`에서 나온다(사용자: ★2 머리 짧게).
- **정의:** `Tools/art/sheets-dream.mjs`(kitSheets · kitBase2 · kitHead/kitHair · kitOutfitSheets · kitHair2Sheets).
- **조립·내보내기:** `python Tools/art/kit_preview.py <id> <★>`(미리보기 → `Logs/Screens/kit_<id>_<★>.png`). `--export`를 붙이면 `Characters/Evo/k_<id>_<★>_*`를 만들고 `Resources/Rig/evo_rig.json`의 해당 항목을 바꿔 쓴다.
  - 얼굴 분리(`build_spirit_faces.split`)와 공용 표정 `Art/Raw_Dream/faces/fe_*`도 여기서 붙인다.
  - 복장별 몸통·목 프릴은 `body_<복장>` · `collar_<복장>`으로 저장된다.
  - ⚠ `fit_evo_parts.py`를 돌리면 evo_rig.json을 통째로 다시 써서 k_* 항목이 지워진다. 그 뒤에는 export를 다시 돌릴 것.
- **리그 (`CritterRig.Evo.cs`):**
  - 목 프릴 층을 추가했다.
  - `outfit`(pick·climb·carry)에 맞춰 몸통과 목 프릴을 바꿔 그린다.
  - 걷기는 NKK 사람 리그 방식이다: 팔다리 반대 위상, 한 걸음에 두 번 통통, 앞으로 나간 팔은 팔꿈치를 굽히고 짧아 보이게, 발 들기. 스프링은 임계 감쇠라 건들거리지 않는다(사용자 OK).
  - 손 흔들기·폴짝 동안은 웃는 얼굴이다.
- **지금 상태:**
  - 8정령 ★2·★3을 모두 내보냈고 인게임에 나온다(`Logs/Screens/evo_kit_all.png`).
  - 남은 6장: 공용 표정 `evo_faces`, 작업복 climb_3·carry_2·carry_3, ★2 짧은 뒷머리 시트 2장. 오후 9시에 이미지 한도가 풀린 뒤 생성하고 다시 export한다.
- **코덱스 주의:** 계정이 바뀌면 `gpt-6-astra` 외 모델(luna·terra)은 이미지 도구가 없어서 그림이 안 나온다. 모델을 바꿔 시험할 때는 `CODEX_IMAGE_MODEL` 환경변수를 쓴다(`Tools/codex-image.mjs`).

## 다음 세션 시작점 (예전 부품 시트 방식 — 위 공용 틀로 대체됨, 기록용)

1. **뒷머리·다리 분리 부품 생성** (코덱스 한도 필요, 시트 9장): `bash Tools/art/build_evo.sh` — 부품 8장(3행×5열: ★2·★3 머리/뒷머리/몸통/팔/다리 + ★0·★1 몸) → 공용 표정 → `fit_evo_parts.py --preview`. 진화 줄(통짜) 그림은 **다시 뽑지 않음**(사용자: 이미지는 이대로). ⚠ `Art/Raw_Dream/evo_parts_*.png`는 아직 예전 3×3 판이라 `--slice-only`로 자르면 안 됨(정의는 3×5).
2. 부품이 오면 `Logs/Screens/evo_fit_<id>.png`·`evo_joints_<id>.png`로 관절 확인: 목(짧게), 어깨, 팔꿈치, **엉덩이·다리**(새로 넣은 코드, 아직 실제 그림으로 검증 안 됨), **뒷머리가 몸통·손 뒤**로 가는지. 틀리면 `Tools/art/evo_rig_fix.json`(neck/head/shoulderL·R/hair/hip/hipApart/armRest/armScale).
3. Unity: `MoreMush` 메뉴 Rebuild Sprite DB → OutGame 플레이: 들기(꾹 누르기) 버둥버둥, 나무 위 길 따라 오르기·폴짝·사다리, 나무 앞에 그려지는지(방금 고침, 플레이 확인 전), 표정 교체.
4. 달·별: 부품 시트가 아직 없음(위 1에서 같이 나옴). 그 전엔 예전 통짜 그림으로 나옴.

## 한 것

### 시스템 (진화·해금)
- 나무 단계가 오를 때마다 새 정령이 **열리고**(실루엣), **균사석으로 데려옴**: `Defs.UNLOCK_GEM`(CRITTER_JOIN 순서, 첫 정령 0 = 무료 자동 합류). `Game.KidOpen/CanUnlockKid/UnlockKid`, `FarmJoin`은 무료 정령만.
- 각성 = **진화 ★1~3**, 균사석만(`awakenGold` 삭제). 다음 진화가 열리는 단계 `KLV.EvoStage(kid,★)` = 정령이 열린 단계 + ★. `CanAwaken`에 `KidFail.Stage`. `Evolve(out opened)`.
- OutGame 정령 칸(임시, 정령 창 배치 전): 열린 정령 실루엣 / 누르면 데려오기·Lv 업·진화(균사석은 두 번 눌러 확인). 수치 전부 임시. 테스트는 `SaveIO.Suspended = true`로 세이브 안 건드리고 함.

### 그림
- 확정 컨셉 = `Art/Raw_Dream/concept/evo_v1.png`(★0 버섯 → ★1 팔 달린 버섯 → ★2 머리카락·드레스 꼬마 → ★3 긴 머리·주름 치마). 정령별 실제 버섯 `sheets-dream.mjs EVO_SPECIES`.
- 진화 줄(통짜, 칸·아이콘·크기 기준) `Characters/Evo/evo_<id>_<form>` 24장 + 달·별 줄. 부품 `e_<id>_<form>_*`(지금은 3×3 예전 구성: ★0·★1 몸 한 장 = 갓+대 안 나눔, ★2·★3 머리·몸통·팔).
- 수채 필터(코드)는 사용자 거절 → 삭제. 수채로 다시 그리기 시도(`EVO_STYLE`)는 거의 같게 나와 중단, 사용자가 지금 그림으로 확정.
- 거절본: `Art/Raw_Dream/_rejected/evo_pilot_v2.png`(무드보드판).

### 리그 (`Tools/art/fit_evo_parts.py` → `Resources/Rig/evo_rig.json`, `CritterRig.Evo.cs`)
- 관절을 부품 그림에서 점으로 찾음: 목 = 몸통 위 그루터기 ↔ 머리 턱밑 그루터기(얼굴 아래·눈 간격 1.1배 안에서만, 그루터기가 끝나면 멈춤), 턱을 몸통 목 아래쪽에 붙여 목 짧게. 어깨 = 몸통 어깨 혹 원 ↔ 팔 위 끝 원(공 관절). 팔꿈치 = 팔 가운데 분할(`_up/_lo`, 둘 다 팔꿈치 원 포함). 얼굴 = 눈 한 쌍 찾아 이목구비만 떼어 빈 머리 + 얼굴 층(`build_spirit_faces.split`), 표정은 공용 시트 `evo_faces`(아직 미생성 → 지금은 기본 얼굴만).
- 뒷머리: 지금은 머리 그림을 턱선에서 잘라 `_back`(몸통 뒤)·`_front`. 새 부품이 오면 `_hair` 부품을 따로 씀(눈 기준 이마 위치, 머리 따라 돎, 몸통·팔·다리보다 뒤).
- 다리: 새 부품 `_leg`가 오면 엉덩이(치마 밑단 안쪽, 폭 ±17%)에 매달아 몸통 뒤, 발바닥이 바닥. CritterRig에 다리 뼈·스프링(걷기 엇갈림, 버둥 동동, 오르기, 춤) 준비됨 — **실제 그림으로 아직 검증 안 됨**.
- 모습별 크기 k = 진화 줄 그림 키 → 자랄수록 커짐. 두 팔 다 몸통 앞(정면 그림), 팔은 머리보다 앞.
- 움직임: 목표 각도를 스프링으로 따라감(팔꿈치·머리는 늦게 따라와 흔들림). 누르면 갓 통통(★0·★1 몸 / ★2·★3 머리). 표정: 누름 직후 놀람→웃음, work=effort, carry=tired, heart=love, 들림=놀람/안간힘, 오르기=안간힘.
- 진화 표시(발밑 빛·도는 별) 없앰.

### 들기 · 나무 오르기 (`FarmView`, `FarmTreeView.Nav.cs`, `Resources/Rig/tree_nav.json`)
- 0.25초 꾹/끌기 = 갓 잡고 들기(매달림·진자·버둥버둥·말풍선), 짧게 = 톡. 놓으면 가까운 나무 길 마디(80px×화각)에 앉고, 아니면 떨어져 착지 찌그러짐.
- **나무 길 지도** `tree_nav.json`: 나무 그림 1~7마다 눈으로 짚은 마디(u,v 그림 비율; ground 입구 / spot 머무는 곳)와 길(walk 발판 · climb 사다리·줄기·그네 밧줄 · hop 선반버섯 계단). 확인 `python Tools/art/tree_nav_preview.py`(→ `Logs/Screens/tree_nav_<n>.png`). 새싹(tree_0)은 지도 없음. 게임 좌표에서 마디가 그림과 맞는 것 확인함(`Logs/Screens/nav_play2.png`).
- 쉬는 정령이 가끔(30%, 동시에 4마리까지) 가장 가까운 입구로 가서 BFS 경로로 오름(사다리 느리게·계단 폴짝). 위에서 6~11초 놀기(근처 나무버섯 따기·하트·춤·말하기), 40% 확률로 옆 머무는 곳으로 옮기거나 길 따라 내려옴.
- 나무 위 정령이 나무 뒤로 숨던 것 고침(정렬 순서 = max(나무+10, 1000+y)) — **플레이 확인 전**.

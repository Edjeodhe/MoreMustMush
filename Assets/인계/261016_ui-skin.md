## 확인 방법
1. 잠금 잡고 플레이 → OutGame에서 오른쪽 아래 정령 칸을 펼쳐(`Down_Panel` 누름) 정령 그림이 칸 안에서 원래 비율인지.
2. MainGame에서 수확기 버튼 → 카드 그림 비율, 이름표가 카드 안인지, 설명이 민트 칸 안인지.
3. 의뢰 버튼 · 설정(톱니/Esc) · MainMenu 초기화 → 수채 창·버튼 글자 대비.
- 전후 화면: `Logs/Screens/ui_skin_before_after.png`(왼쪽 전/오른쪽 후: 설정 · 의뢰 · 수확기), `ui_after_reset.png`, `ui_after_mainmenu.png`, `ui_after_farmtab_grow.png`.

## 남은 것 (선택)
- MainGame 모달 뒤 어두운 막이 아래 이동 버튼 줄은 덮지 않는 것처럼 보임(다른 캔버스 정렬일 수 있음). 확인 안 함.
- 수확기 카드 설명이 영어에서 10~12pt까지 작아짐 — 설명 줄이기 또는 카드 키우기는 디자인 결정.
- `DreamUiSkin`을 다시 돌리면 4개 씬을 저장하므로, 다른 세션이 씬을 쓰는 중이면 돌리지 말 것.

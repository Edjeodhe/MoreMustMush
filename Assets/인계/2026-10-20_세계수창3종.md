## 남은 것·참고
- 꼬마 구역 바꾸기·선물은 옛 꼬마 탭에 있던 기능 — 지금은 꼬마 정보 카드(구역)와 호감도 팝업(선물)에 있음.
- 다른 언어에서 버튼·제목 길이 확인 안 함.
- 이번 세션에서 Unity가 다른 사람의 플레이 중에 컴파일되어(도메인 다시 로드) OutGameController NullReference가 잔뜩 찍혔던 적 있음 → 플레이 중엔 컴파일하지 말 것.

## 추가 (같은 세션) — 시안 그림 그대로 · 꼬마 카드 2장 · 나무버섯 숨김
- 사용자: "꼬마 창엔 인게임 꼬마 사진 말고 시안의 새싹·이슬 그림 그대로, 새싹 = 호감도, 이슬 = 별 등급, 이름 글씨는 지움" + "보낸 사진들 다 그대로 UI에".
- `Tools/art/crop_mock_ui.py`: 시안에서 그림 10장을 잘라 `UI/Window/mock_*.png` — 새싹·이슬 카드, 부탁 꼬마, 진화 화분(꼬마 창), 나이테·공물·가호·진화 동그라미(성장 창), 잠긴 슬롯 자물쇠·그림 뒤 물감 배경(공방 창). 상자 좌표를 바꾸고 다시 돌리면 된다.
- 꼬마 창: 카드 = `Card_Aff`(새싹 그림 · 꼬마 n명 | 호감도 합 · 하트 = 평균 호감도 · [호감도]) + `Card_Grade`(이슬 그림 · 별 합/최대 · 별 = 평균 등급 · [등급] → 꼬마 등급 팝업). 이름 알약 없음. 부탁 말풍선은 시안 문장 "매일 세 번, 함께하는 작은 일을 부탁할게요!". 합류 목록은 아래 꼬마 칸에서 없는 꼬마를 누르면.
- 세계수 나무버섯: `FarmTreeView.ShowFruits = false` — 걸린 나무버섯 그림·짚기를 끔. 수확 규칙(보따리 → "수확 보따리 받기")은 그대로, 꼬마들은 계속 자기 구역에 가서 따 온다. 나무 그림에 그려진 보라 선반 버섯(정령 길 발판)은 그림 자체라 남아 있음.

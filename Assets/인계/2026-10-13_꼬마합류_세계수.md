# 2026-10-13 꼬마 합류를 세계수 레벨로 (LKH 브랜치)

```
[목표] 신규콘텐츠 기획서 Ver03("꼬마버섯 세계수")대로, 꼬마가 라운드에 나타나 잡히는 대신 세계수 레벨이 오를 때 합류하게 한다.
[현황] 적용 완료. 에디터 컴파일·씬 검사 오류 0, 합류 로직 검증, 플레이 모드로 새 게임→세계수→레벨 업→라운드→정산 확인. 미커밋.
[반환] 기존 인계는 고치지 않는다. 세계수 8단계 개편 등 후속 작업은 새 인계에 남긴다.
```

## 다음 세션 시작점

1. 사용자 확인 후 커밋한다.
2. 밸런스 팀: 라운드 시작 때 꼬마 등장 확률을 굴리던 난수 1회가 사라졌다. 같은 시드라도 시뮬 결과가 예전과 달라진다(의도된 변경). 다음 측정부터 새 기준으로 본다. `ed_special` 노드도 삭제됐다(`Defs.Prices.cs`에 가격 줄이 남아 있지만 쓰이지 않는다. 다음 가격 맞추기 때 자동으로 빠진다).
3. 기획서의 나머지(세계수 8단계·경험치·진화 재료, 꼬마 레벨·각성, 장식 24종, 수확 구역, 가호)는 이번 범위 밖이다.

## 사용자 결정 (2026-10-13)

- 세계수 Lv = 기획서 단계. **Lv.1 새싹(새 게임 시작 때) · 2 이슬 · 3 바람 · 4 불씨 · 5 조약돌 · 6 찌릿 · 7 달빛 · 8 별똥**. Lv.9~10은 합류 없음. 세계수 구조·비용은 그대로
- 동전·꿀밤 꼬마(기획서 "2차 추가")는 지금 얻을 수 없다. 도감·칩에는 잠긴 채로 보이고 도감 설명은 "2차 업데이트에서 만날 수 있어요"
- 라운드 꼬마 등장과 노드 "꼬마 손님(`ed_special`)" 삭제
- 예전 세이브: 이미 잡은 꼬마는 그대로 두고, 세계수 레벨까지 빠진 꼬마만 채운다

## 바꾼 것

- `Defs.CRITTER_JOIN`(합류 순서), `Defs.JoinLv(id)` (0 = 2차). `SPECIAL_P`·`SPECIAL_LIFE` 삭제
- `Game.FarmJoin()`: 세계수 레벨까지의 꼬마를 합류시키고 새로 들어온 꼬마를 돌려준다. `AutoEnsure`(새 게임·이어하기·복귀)에서 부른다
- `Game.TreeUp(out joined)`: 레벨 업 → 합류 → 첫 부탁 시각(`FarmEnsure`) → 저장. `GameFlow` "treeup" 토스트에 "○○ 꼬마 합류!" 줄 추가, 농장에 바로 걸어 들어온다
- 라운드: `SpawnSpecial`·`HitSpecial`·`CatchSpecial`·`UpdateSpecial`, `RoundSim.special/specialAt/specialGot`, 공의 꼬마 충돌, `SpecialMush`, `RoundStats.specialP/specialLife`, 정산 "NEW 꼬마" 카드·보너스 골드의 "특수 버섯" 항목, `RoundView.DrawSpecial`과 꼬마 이름·시간 글자 삭제
- 씬: `World/Round/Field/Special`(꼬마 리그)·`SpecialRing`·`SpecialRingBack`·`SpecialHpBack`·`SpecialHpFill`·`SpecialShadow`, 디버그 `dbg-special` 버튼 삭제. `TreeSync`로 `ed_special` 노드 삭제·재배치(121개)
- 문구: 도감(합류 레벨 안내), 세계수 빈 화면, 버섯 따기 안내, 스킨 버튼, 디버그 "꼬마 10종을 모두 합류시켰어요"
- `MoreMush/다국어/3 번역표 갱신`(키 1153개, 지운 줄 19), `4 폰트 굽기`(새 글자 반영)

## 검증

- 에디터 실행 검증: 새 게임 → 새싹만 · TreeUp마다 Lv2 이슬 … Lv8 별똥 · Lv9·10 합류 없음 · 새 꼬마 부탁 시각 생성 · 예전 세이브(Lv3 + 별똥·동전) → 유지 + 새싹·이슬·바람 · `JoinLv(coin/chest)=0` · 노드 121개

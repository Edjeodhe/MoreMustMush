## 꼬마 작업 배정 카드 (`Resources/UI/KidInfoCard.prefab`, `KidInfoCard.cs`)
- 사용자가 프리팹 `Card` 아래에 `Zone_Button` 5개(휴식·뿌리·줄기·수관·가지)를 배치했다.
- `Button_Zone`(구역: ○○)을 누르면 5개가 펴지고 접힌다. 하나를 누르면 `Assign(꼬마, 구역)`으로 보낸다.
  - 지금 구역 = 노란빛, 안 열린 구역 = 흐린 글자 + 누르면 "세계수가 N단계가 되면 열려요", 자리 없음 = 알림.
- **Zone_Button은 이름이 다 같아서 버튼 글자(한국어 원문)로 구역을 안다.** 프리팹에서 글자를 바꾸면 그 버튼은 연결되지 않고 콘솔에 경고가 뜬다.
- 새 번역(String 시트·db.json): `휴식`(901436, 일본어는 폰트에 `憩`가 없어 `お休み`), `{0}에 자리가 없어요 (최대 {1})`(901437). 도감 탭 `독버섯` 영어 `Poisonous Mushroom` → `Poisonous`.

## MainGame 수확기 카드 (`HarvesterShop.cs`, 씬 `Canvas/Harvesters/Harvesters (1~8)`)
- 배치: 이름(Panel) → 그림(Image) → **Stars** → Line_Top → 설명(Panel (1)) → Line_Bottom → 버튼. 2~8번 카드를 사용자가 고친 1번 배치에 맞췄다.
- **Stars**: `Star1~5`(Icons/star, 30×30, 가로 정렬 가운데). 강화 단계(★)만큼 앞에서부터 켠다. Stars가 없는 카드는 예전처럼 설명 첫 줄에 ★☆ 글자.
- 설명 박스: `Panel (1)`의 Image를 껐다(글자만). 위아래 구분선 `Line_Top`·`Line_Bottom`(270×2, 갈색 반투명).
- **실행 시 설명 박스·버튼을 사각형으로 바꾸던 `SquareBoxes` 코드를 지웠다** → 에디터에 배치한 그림(btn_go·btn_orange 등) 그대로 나온다.
- 켜진(장착한) 수확기의 `Button_Buy` = 노란 **`UI/btn_active`**(btn_go를 노랗게 칠한 것, 9분할 테두리 같음, SpriteDB·`MoreMushSetup` 9분할 목록 등록). 글자는 진한 갈색. 꺼지면 배치한 그림으로 돌아간다.
- 강화 버튼의 "★N + 가격" 글자와 강화 알림 글자는 글자 그대로 두었다.

## MainGame 팝업 리본·버튼 순서
- 도감(`MushDex/Ribbon`)·수확기(`Harvesters/Ribbon`) 위 가운데에 옵션 패널 프리팹과 같은 리본 + 제목(LocText 키 `도감`·`수확기`, ONE Mobile POP + Title Outline 머티리얼).
  - 도감 = 옵션 창과 같은 600×120. 수확기 = 0.72배(432×86): 수확기 창 위 끝이 골드·균사석 표시에 붙어 있어 그 사이에 맞춤. 더 키우려면 수확기 창을 내리거나 줄여야 한다.
- 하단 버튼(의뢰·세계수·도감·공방)을 팝업 뒤로: 세 버튼에 정렬 캔버스를 붙여 팝업 위로 올리던 `MainGameController.LiftAbovePopups` 삭제, 의뢰 버튼 `Quset`을 Canvas에서 `MainBG` 바로 다음(팝업보다 앞)으로. 팝업에 가려진 부분은 눌리지 않는다.
- 의뢰 창은 실행 중에 만드는 임시 창(`QuestWindow.BuildTemp`). 리본 제목 글자를 옵션 패널 프리팹 제목 설정(폰트·머티리얼·색·크기 비율)으로 맞추는 `MatchRibbonTitle` 추가. 리본 그림 크기(560×168)는 그대로.

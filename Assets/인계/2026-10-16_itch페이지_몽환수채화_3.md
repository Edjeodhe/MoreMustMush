## 알게 된 것
- Unity MCP: 이 세션엔 도구로 안 붙어 있어서 `http://127.0.0.1:8080/mcp`에 HTTP로 직접 JSON-RPC 호출(세션 scratchpad의 umcp.py). 다음 세션부터 쓰려면 `claude mcp add --scope local --transport http UnityMCP http://127.0.0.1:8080/mcp` (이번엔 claude CLI가 PATH에 없어 등록 못 함)
- 에디터 메뉴 빌드는 "Scene(s) Have Been Modified" 창에서 멈춘다 — AspectLetterbox(ExecuteAlways)가 카메라 모드 캔버스의 match 값을 써서 씬이 더러워짐. 빌드 전에 씬 저장
- itch 편집기 이미지: Pick image가 만드는 file input을 `HTMLInputElement.prototype.click` 가로채기로 잡고, 여러 장은 내 `<input multiple>`에 한 번에 올린 뒤 DataTransfer로 한 장씩 넣으면 빠르다
- itch 글꼴 select는 JS로 바꾸면 창이 안 뜬다 → 포커스 후 키(Home/Down)

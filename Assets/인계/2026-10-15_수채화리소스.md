## 다음 세션 시작점

1. 균사 트리 화면 배경: 카메라 배경색(#1A120C 진갈색)만 있다. 밝은 수채화 톤과 어긋나므로 배경 그림을 넣을지 사용자에게 묻는다 (노드 글자가 흰 글씨 + 어두운 외곽선이라 중간 밝기 이하가 필요)
2. 엑셀 DB Skill 시트 Icon 칸: `homing`→`s_homing`, `power`→`s_power`, `barclone`→`s_barclone` (새 아이콘은 이미 있음. 지금은 기존 대체 아이콘을 씀). COM으로 고칠 것
3. 타이틀 할아버지 낫 끝이 제목 글자 "More"에 살짝 걸친다. 거슬리면 `Tools/art/rig_soft.json`의 grandpa `Parts` 스케일(0.32)을 낮추고 `MoreMush/Art/Apply Soft Rig Layout`

## 구조

- `Assets/Art/Soft/` = 새 그림. 키(경로)는 `Assets/Art/Generated/`와 같다. `MoreMushSetup.ArtRoots`가 Generated → Soft 순이라 같은 키면 Soft가 이긴다 (SpriteDB, 텍스트 아이콘, 9-슬라이스, 아틀라스 모두 `ResolvedArt()` 사용). Generated는 지우지 않았다(되돌리기·비교용)
- 원본 시트: `Art/Raw_Soft/<id>.png` + 프롬프트. 정의: `Tools/art/sheets-soft.mjs`, 가이드: `Tools/art-style-soft.md`
  - 생성: `node Tools/art/build-art.mjs --set soft [id...]` (원본이 있으면 재사용, `--force`로 다시 그림, `--slice-only`로 자르기만)
  - 생성기가 행·열을 바꿔 그리는 일이 잦다(보스 3×2, 아이콘B 6×5, 꼬마 원본 5×2). 정의에 실제 배치를 적어 둠. 다시 그리면 자른 결과를 꼭 확인
  - `slice_sheet.py`: 반투명 후광 잡티 제거 추가, 이름에 하위 경로(`Farm/Icons/req_water`) 허용
- 새로 생긴 그림: 약초 괭이(`Harvesters/hoe`), 스킬 `s_homing·s_power·s_barclone`, 보스 5종(`Bosses/<id>`, 코드는 원래 있으면 씀), 지역 배경 `bg_night·bg_sea·bg_ruins`(+`bg_field`를 라운드용으로), 세계수 8단계 `tree_0~7`, 장식 24종 각자 그림(`Farm/Props/<장식 id>`)
- 코드 변경: `Defs.Farm` 장식 `art` = 장식 id, `WT.Picture` 단계마다 그림 하나, `WT.width` 8칸, `ACC_PLACE` 새 갓 크기에 맞춤, `FarmTreeView.FruitPx` 8단계 기준
- 꼬마 리그: 부품 크기가 달라져 배치를 새로 잡음. 갓·스킨 20장은 같은 크기(아래 정렬)로 맞춤. 배치표 `Tools/art/rig_soft.json` → 메뉴 `MoreMush/Art/Apply Soft Rig Layout` (CritterRig 프리팹, CritterIcon 20개, GrandpaRig 프리팹)
- 할아버지 리그: `Tools/art/build_grandpa_rig_soft.py`가 사람 얼굴 할아버지 그림을 몸통·낫(몸 뒤, 손목 축)·눈 감기 패치로 자른다. head_cover는 빈 그림(필요 없음)
- 씬/프리팹 참조 교체: 메뉴 `MoreMush/Art/Use Resolved Art In Scenes and Prefabs` (491개 교체)

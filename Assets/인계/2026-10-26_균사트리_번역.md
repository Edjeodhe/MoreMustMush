## 찾은 것 (번역 안 되던 원인)
| 문구 | 원인 |
|---|---|
| 아래 버튼 `MushTree`·`MushDex`·`Harvesters`, `Stage Start` | 씬(MainGame)에 영어로 적어 둔 글자. LocText도 없고 코드도 안 건드려 모든 언어에서 영어 |
| `25 Stage` | `Stage_Text`의 "N Stage" 틀에 숫자만 넣고 있었음 |
| 설정(톱니) 창 전체 | 임시 창(`TempDialog`)이 만들 때의 언어로 고정. 언어를 바꿔도 다시 안 적음 |
| 설정 창 `소리 설정·효과음·배경음·음소거: 켜짐/꺼짐·메인 메뉴`, 노드 `희귀 포자`(ed_rare0) 이름·설명·효과 | DB String 시트에 줄은 있지만 번역 칸이 비어 있어 한국어로 나옴 (콘솔 경고 없음 — 빈 칸은 경고를 안 띄운다) |
| 노드 설명 창(마우스 올림) | 같은 노드를 다시 짚으면 글자를 다시 안 만들어서, 언어를 바꾼 뒤 옛 언어 글자가 남음 |

노드 이름표·설명 문구 자체(`Defs.Nodes`)는 이미 `Loc.T`를 거치고 있었고 정상이었다. 수확기·도감·의뢰 창도 정상.
`Lv 0/3`, `MAX`, 설명 창 `LVL 2 / 2`는 한국어에서도 같은 표기라 그대로 뒀다.

## 바꾼 것
- `Assets/Scripts/Flow/MainGameController.cs`: `LABELS`(Button_MushTree=세계수, Button_MushDex=도감, Button_Harvesters=수확기, Button_StageStart=시작하기) — 영어에서는 씬에 적어 둔 글자 그대로, 다른 언어는 `Loc.T`. Stage_Text도 영어는 "N Stage" 틀, 다른 언어는 `Loc.F("스테이지 {0}")`. Start와 `OnLang`에서 다시 적는다. 폰트는 기존 TextLangFont가 바꾼다(LocText를 붙이지 않음 — 붙이면 ONEMobilePOP이 세트 폰트로 바뀐다). 문구는 모두 DB에 이미 있던 것.
- `Assets/Scripts/UI/OptionWindow.cs`: 임시 창 글자마다 한국어 원문을 기억(`tempTexts`)하고 `Refresh()`(열 때마다 불림)에서 지금 언어로 다시 적는다. `Extra.label`은 이제 **한국어 원문**을 넘긴다(창이 번역).
- `Assets/Scripts/Flow/OutGameController.cs`·`StageController.cs`: 위에 맞춰 `Extra` 라벨에서 `Loc.T` 뺌.
- `Assets/Scripts/Tree/TreeTooltip.cs`: 다시 그릴지 판단에 `shownLang` 추가.
- 엑셀 `Assets/DB/MMM_DB_Ver.05.xlsx` String 시트(COM, `db_write.py set`, uv로 실행) → `DbImport.Import()`로 db.json 다시 만듦. 번역 40칸: 303033 희귀 포자, 203033 그 설명, 901324 에픽 이상 가중치 ×{0}, 901325 언어, 901326 소리 설정, 901327 효과음(SFX/効果音/Эффекты/Ефекти), 901328 배경음(Music/BGM/Музыка/Музика), 901329 메인 메뉴, 901330~901331 음소거: 켜짐/꺼짐. db.json 차이는 이 40칸뿐임을 확인.
  - 엑셀 백업: 스크래치패드 `MMM_DB_Ver.05.backup.xlsx`(세션 임시 폴더라 곧 사라짐)
- 폰트 굽기(메뉴 4)는 하지 않음 — 새 글자가 모두 이미 구운 폰트에 있었다(활성 TMP 전부 `HasCharacter` 검사, 언어별 0개).

## 결정할 것
- 영어에서는 아래 버튼을 디자이너가 적은 `MushTree`·`MushDex`·`Harvesters`·`Stage Start`·`25 Stage` 그대로 뒀다. DB 영어(World Tree·Collection·Harvester·Start·Stage 25)로 통일하려면 `MainGameController.RenderLabels`/`RenderStage`의 `Loc.Lang == "en"` 분기를 빼면 된다.
- ru·uk의 `Мировое древо`·`Світове дерево`는 버튼에 길어서 자동으로 작게 줄어든다(읽힘). 짧은 이름이 필요하면 별도 문구를 정해야 한다.

## 확인 방법
1. `Temp/unity_editor.lock` 잡기 → MainGame 플레이 → 실행 코드로 `MoreMush.Loc.SetLang("ja")` 등 (언어마다 **호출을 나눠** 한 프레임 넘긴 뒤 검사 — 한 호출에서 연달아 바꾸면 노드 이름표가 아직 안 그려져 빠진 글자처럼 보인다)
2. 설정 창은 `MainGameController.Toggle(OptionPanel)`(비공개, 리플렉션)로 연다
3. 스크린샷: `Captures/loc_tree/`(ko·ja·uk·en 트리 화면, ja·ru 설정 창, 고치기 전 ko·ja)
- 플레이 확인 후 에디터 PlayerPrefs 언어는 en으로 남아 있다(원래 값 모름).

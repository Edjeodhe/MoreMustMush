## 남은 일
1. ~~꾸밈 시트 자르기~~ 끝: `python Tools/itch/cut_deco.py` → `out/deco_*.png` 22장(칸은 스크립트 BOXES에 손으로 잡음) + `little_ones.png`(꼬마 6명 한 줄) + `divider.png`(넝쿨). 번호 배지 `deco_badge_1~4`는 GIF 카드 합성에 쓸 것. 설명 초안에 클로버 구분선·세계수 그림 자리 추가.
   - WebGL 빌드는 webgl-size 세션이 160MB로 줄여 `Builds/MoreMustMush_WebGL.zip`에 다시 만들어 둠(17:45).
2. **GIF 4개·스크린샷 녹화** (webgl-size 세션이 Unity를 다 쓴 뒤): 플레이 모드 → `SaveIO.Suspended=true`, `Application.runInBackground=true`, `Loc.Lang` en 확인. 녹화는 execute_code로 `EditorApplication.update` 콜백 + `Time.captureFramerate=25` + **매 프레임 GameView `Repaint()`**(안 하면 백그라운드에서 화면 저장이 안 됨) + `ScreenCapture.CaptureScreenshot` → `Temp/itchcap/<clip>/f00001.png`. 바 자동 추적은 `InputSystem.QueueStateEvent(Mouse.current, MouseState{position})`, 발사는 `RoundSim.R.Launch(각도)`. 세이브는 47스테이지라 수확·피버 장면 가능. 세계수 장면은 `G.farm.stage=8`, `CRITTER_JOIN` 전원 `G.specials[id]=true` → `Game.FarmJoin()` → `FarmView.I.Sync(false)`, ★3은 `G.farm.awaken[id]=3`. (이번에 찍은 `harvest2`는 수확 화면이 덜 그려진 상태라 못 씀 — 라운드가 제대로 시작됐는지 확인하고 다시 찍을 것.)
   - GIF 카드는 `Tools/itch/build_itch.py`의 make_clip/make_card_gif를 크림 종이·갈색 글씨로 바꿔 쓰면 된다. 스크린샷 4~5장(수확·피버·균사 트리·세계수·꼬마 진화)은 Edit game의 Screenshots(사이드바)에 교체.
3. **itch 입력(저장 전 사용자 확인)**: 테마 값 입력 → 설명 글 HTML 붙이고 이미지 교체 → 커버·스크린샷 교체 → 새 zip 업로드("played in the browser" 체크, 예전 zip 삭제는 확인 뒤) → Mobile friendly 체크 여부는 사용자에게 물을 것.
   - 크롬 요령: 색 칸은 JS로 값만 바꾸면 미리보기가 안 바뀐다 → 칸을 triple_click 후 type. 글꼴은 select를 `_select_google_font`로 바꾸면 검색 창이 뜨고, 한 번에 하나씩. 이미지 칸은 Remove image 후 Upload 버튼이 만드는 file input을 `HTMLInputElement.prototype.click` 가로채기로 잡아 label로 감싸 DOM에 붙이면 `file_upload`가 된다. 상단 바(Edit game 링크 등)를 잘못 누르면 미리보기가 날아간다.
4. 새 빌드 올린 뒤 시크릿 창에서 **영어로 시작**하는지, 전체화면 버튼으로 캔버스가 꽉 차는지 확인 (템플릿 `Assets/WebGLTemplates/MoreMush`가 창 크기를 채움).

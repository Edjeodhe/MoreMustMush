# 2026-10-16 UI 머지 · 새 씬에 게임 시스템 연결

## 인계 블록

- **[목표]** UI_Construction(새 씬 4개)을 KHD에 머지하고, UI가 아직 배치되지 않은 게임 시스템(업그레이드 트리·라운드·기능 해금)을 새 씬에 임시로라도 이어 플레이가 한 바퀴 돌게 한다.
- **[현황]**
  - 머지는 사용자가 `32e7dbf [MOD] UI머지`로 커밋함. 머지 때 Tutorial.cs 삭제, ArtSoftRig의 CritterIcon 부분 삭제, 에디터 툴·Tools 경로 `Assets/Art` → `Assets/Resources/Art`.
  - 이번 세션 변경은 **미커밋**: MainGame 트리, Stage 라운드 월드·HUD, 해금, "?" 노드 숨김.
  - 플레이 확인: MainGame → 출발 → Stage(라운드 진행) → 종료 → MainGame, 4스테이지 세이브로 해금 확인. 에디터 세이브는 테스트 전 백업 → 테스트 뒤 되돌림.
- **[반환]** 사용자 확인 후 커밋. 아래 "남은 일"은 UI 배치가 나오는 대로.

## 다음 세션 시작점

1. Stage 정산 창이 배치되면 `StageController.Finished`에 연결 (지금은 끝나면 바로 MainGame).
2. 업그레이드 트리 UI가 배치되면 임시 트리(`TreeWorld`·`Scripts/Tree/*`·`Prefabs/Tree`)를 걷어내고 그쪽에 연결.
3. 튜토리얼(옛 `Tutorial.cs`, KHD 이력에 있음)을 새 씬에 맞게 다시 — 코드로 오버레이를 만들던 방식이라 배치된 UI가 필요.
4. 보스 도전 켜기/끄기(`G.bossOn`), 기록·스킨 창: 배치 대기. 의뢰 창은 임시 창으로 연결됨 — `QuestPanel`을 배치하면 `QuestWindow` 머리 주석의 이름대로 잇는다.
5. OutGame 세계수 월드(`FarmView`): 사용자가 배치한 나무 그림(`Resources/Sprite/Tree`)과 겹쳐서 이번엔 옮기지 않음.

## 리소스 방침 (사용자)

- `Assets/Resources/Art`(Generated·Soft)는 예전 웹 버전 그림. 앞으로 쓸 그림은 `Assets/Resources/Sprite`.
- 배치된 UI에 들어간 그림만 쓰고, 새 그림은 사용자가 나오는 대로 적용한다.
- 아직 Art 그림을 코드가 붙이는 곳: 공방 카드 아이콘(`HarvesterShop`), 도감 그림(`MushDexPopup`), OutGame 꼬마 칸, 임시 트리·라운드 월드 전체.

## 알려진 것

- 알림(`App.Notify`)을 그리는 UI가 없어 로그로만 나옴 → 해금 알림·"골드가 부족해요"도 아직 안 보임.
- 1스테이지 세이브(지금 에디터 세이브)는 트리가 안 보이는 게 정상(해금 전).
- 에디터 창이 포커스가 없으면 플레이 모드 프레임이 안 넘어감 → MCP 테스트는 일시정지 + `EditorApplication.Step()`.

# itch 커버 v5 '대비·주인공 하나' (2026-10-20)

v4(통 일러스트 A·B)는 "둘 다 별로" → `분석.md` 인기작 규칙에 비춰 본 원인:
- 화면 전체가 밝은 연두·노랑 → 제목·주인공이 안 튐(명암 대비 없음).
- 버섯 수십 개·코인 20개·그루터기 → 목록 크기에서 산만.
- 정령이 높이 40%로 오른쪽 구석, 가운데 수확기와 시선 다툼.
- 색이 많음(연두·빨강·금·하늘).

v5 규칙: 배경은 짙은 청록(C)·남청(D) 숲 그늘 + 가장자리 어둡게, 정령만 따뜻한 빛 / 정령 높이 60~65% / 수확기는 왼쪽 아래 앞에서 버섯을 베는 중, 크림색 궤적 하나 / 코인 6~7개 + 잘린 갓 3~4개만 정령 위로 호를 그림 / 코랄·크림·청록·꿀색만 / 왼쪽 위는 로고 자리로 비워 둠.

- 생성: ChatGPT 웹(앱 브라우저, 사용자 계정), v4와 같은 대화 https://chatgpt.com/c/6ad6db13-68f0-83e8-a27f-0940935fd507 (정령+수확기 시트 첨부). 둘 다 1402×1122(5:4).
  - C: 낮 숲 그늘, 정령이 오른쪽에서 뛰며 환호.
  - D: 해 질 녘 남청색, 정령이 더 크고(65%) 정면, 궤적이 정령 뒤로 감김.
- 받기: 캔버스 → WebP → `Tools/rig-web/receive.html` → `Logs/Screens/v5_*_raw.png` → `C_raw.png`·`D_raw.png`.
- 합성 `compose.py` = v4 것 + `--vig`(가장자리 짙은 청록 비네트):
```
python v5/compose.py C C --logo 0.54,0.03,0.04 --vig 0.35
python v5/compose.py D D --logo 0.54,0.03,0.04 --vig 0.35
```
결과 `out/cover_<C|D>_1260x1000.png`(업로드용), `_630x500`, `preview_*_315x250`, 비교 `out/시안2종.png`(아래 줄: v5 C·D, v4 A, 지금 itch 커버를 315×250으로).

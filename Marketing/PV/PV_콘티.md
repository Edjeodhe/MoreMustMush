# MoreMustMush 30초 PV 콘티

NKK PV v3 방식(동사 카드 ↔ 짧은 인게임, 0.5초 박 격자, 중반 스토리 컷, 로고 엔드카드 + 아이리스 아웃)을

- 연출: 수채 방사형 카드(색만 바꿔 장 구분) · 인게임 스프라이트를 움직인 짧은 애니 · Codex 일러스트

## 녹화 목록 (Unity 에디터, 1920×1080, 30fps 고정 프레임)
- R1 Stage 한 판: 바 자동 추적, 높은 스테이지(콤보·스킬이 열린 세이브), 약 15초
- R2 MainGame 균사 트리: 커서 이동·툴팁·구매, 약 4초
- R3 OutGame 세계수: 8단계·정령 8명, 약 4초
- R4 보스 스테이지 3종, 각 약 3초

## 소리
게임 효과음이 코드 합성(Snd.cs)이라 음원 파일이 없다 → 120BPM 오르골·피치카토풍 음악과 팝 효과음을 파이썬으로 합성해 박에 맞춘다.

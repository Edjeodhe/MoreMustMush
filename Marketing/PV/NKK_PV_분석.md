## 특징 정리

- **비율**: 연출 애니(카드·일러스트·엔드카드) 약 26.5초(67%) : 인게임 약 13초(33%). 인게임은 2~4초씩 짧게 끊고, 카드가 "무엇을 하는 게임인지"를 먼저 말해 준다.
- **템포**: 모든 전환·글자 팝이 0.5초(한 박) 격자에 맞는다. 몽타주는 0.7~1.3초, 의성어는 박마다 하나.
- **메카닉 설명 방식**: 문장이 아니라 **동사 한 단어**(SMASH / SWARM / STEAL / UPGRADE). 느낌표 개수가 늘어나며 고조. 30초 초안의 문장 자막("They experimented on us." "Breed.")을 v3에서 동사 카드로 바꾼 게 가장 큰 변화.
- **텍스트·로고 배치**: 카드에선 화면 가운데 위쪽 큰 글자, 인게임 위 의성어는 모서리 교대, 몽타주는 하단 고정 띠 자막. 로고는 엔드카드에서만 크게.
- **전환**: 캐릭터가 글자를 부수거나 훔쳐 가는 식의 "글자와 캐릭터의 상호작용", 박에 맞춘 하드 컷, 색이 다른 방사형 배경으로 장 구분.
- **이야기 한 덩어리**: 중반 뒤(23~29초)에 6초짜리 짧은 스토리 컷(위기→반전)을 넣어 기능 나열에 숨을 준다.
- **소리**: 처음부터 끝까지 음악 + 효과음 (RMS −10~−24dB, 박마다 강세).
- **마무리**: 로고 + PLAY NOW, 아이리스 아웃.

## MoreMustMush에 옮길 때 바꿀 점

- 화풍이 몽환 수채화(조용한 숲)라 만화식 원색 방사형 대신 **수채 종이 방사형**(크림·세이지·살구·라벤더)으로 톤을 낮추고, 글자는 로고와 같은 크림 글자 + 갈색 테두리.
- 우리 게임의 볼거리는 인게임(바·공·버섯·숫자·스킬)이 강하므로 비율을 **연출 45% : 인게임 55%** 정도로 인게임 쪽을 늘린다.
- 30초에 맞춰 동사 카드 4장(BOUNCE / COMBO / GROW / FRIENDS) + 보스 스토리 컷 + 보스 몽타주 + 엔드카드.

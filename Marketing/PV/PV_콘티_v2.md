# MoreMustMush 30초 PV 콘티 v2 — 「할아버지와 버섯 정령의 숲속 하루」

버섯을 너무 좋아하는 할아버지가 버섯 정령들과 숲속에서 사는 **하루(아침 → 낮 → 저녁 → 밤 → 다음 날 아침)**를 따라가면서 핵심 메카닉을 하나씩 보여 준다.
v1처럼 색이 다른 방사형 카드로 장을 나누지 않고, **하루의 빛(시간대)**으로 장을 나눈다.

- 규격: 1920×1080, 30fps, 120BPM(한 박 0.5초). 전환과 글자 팝은 모두 박에 맞춘다.
- 그림체: 지금 수채화 플랫을 그대로 쓴다(종이 질감, 둥근 형태, 부드러운 번짐). 장면 전환은 **물감이 번지며 다음 장면이 칠해지는** 수채 와이프.
- 글자: Jua, 크림 글자 + 짙은 갈색 테두리, 강조는 산호색. 영어(itch 대상). 메카닉은 문장이 아니라 **동사 한두 단어**로.
- 비율: 연출(할아버지·정령 일러스트) 약 13초 : 인게임 약 17초.
- 할아버지는 사람 얼굴. 게임에서는 타이틀과 균사 트리에만 나오므로, PV에서도 연출 컷에서만 크게 쓴다.

## 흐름 요약

- 0~4초: 할아버지가 누구인지(버섯 덕후)와 제목을 보여 준다.
- 4~12.5초: 한 판의 고리. 쳐서 수확하고, 콤보를 쌓고, 팔고, 새 버섯을 모은다.
- 12.5~20.5초: 바깥 성장. 균사 트리와 정령 마을.
- 20.5~25초: 위기와 목표. 보스.
- 25~27초: 방치해도 자란다.
- 27~30초: 로고와 다운로드 안내.

## 필요한 자료

**새로 그릴 일러스트 (Codex, soft 세트 스타일, `Art/Raw_Soft/pilot.png` 참고)**
- `pv2_morning`: 안개 낀 아침 숲 + 오두막 (배경, 레이어 분리: 하늘 / 먼 나무 / 오두막 / 앞 덤불)
- `pv2_grandpa_mush`: 버섯을 집어 들고 눈이 반짝이는 할아버지 (상반신, 사람 얼굴)
- `pv2_basket`: 바구니 지고 걷는 할아버지 (2프레임이면 충분)
- `pv2_mycelium`: 땅에 손 짚은 할아버지 + 빛나는 균사 (균사는 코드로 그려서 뻗어 나가게)
- `pv2_night`: 밤 숲 모닥불, 졸고 있는 할아버지
- 보스 등장은 v1 `boss_scene`을 저녁 톤으로 다시 칠하거나 그대로 재사용

**정령 동작 (리그2 웹 작업장 `Tools/rig-web`에서 뽑기)**
- 덤불에서 고개 쏙 / 깃발 응원 / 사다리·줄기 오르기(뒷모습) / 망치질 / 놀라서 숨기 / 등불 들고 걷기 / 손 흔들기(v1에 있음)

**인게임 녹화 (v1 `Temp/pvcap` 재사용 + 새로 찍을 것)**
- 재사용: round, tree, boss 3종
- 새로 찍기: 지금 농장(정령 마을) 수확·건축·별 등급, 정산 화면(새 버섯 카드 포함), 자동 수확 보상 창
